# ChatUI v2.1.7

ChatUI v2.1.7 完善意图识别的决策规则并移除一处领域词白名单兜底，修复短视觉约束继承时 goal 重复拼接的问题。

## 改进

- 复杂路径路由提示词现在携带完整规则集（COMPACT 与 FULL 一致），不再因压缩丢失 relation、goal、文件指代等决策规则。
- 补充关系边界规则：当前上传图的编辑才判 new；纠正前序成果优先判 followup；沿用历史参考图继续生成判 continuation。
- 补充 goal 与资源边界：纠正背景不写入 goal；multi 任务必须写数量词；资源歧义只省略 target 绑定、不删除用户明写的主体词；禁止“三处要求/上述约束”式概括回指。
- 历史文件指代即使缺失仍保持 file_qa；扫描件/图片化文档按 file_qa，仅明确提取文字才 ocr；无动词短名词短语约束继承前序主体。
- 移除“短视觉约束”的领域词白名单正则，改为按前序执行的结构化状态与当前路由语义判定，词表外表达（如“戴帽子的猫”“天花板加吊灯”）也能正确继承前序主体。
- 修复短视觉约束继承时因标点差异导致的 goal 整段重复拼接。

## 稳定性与质量

- 意图识别评测固定 temperature=0，使评测门可复现；scorer 接受“一张…一张…”作为“分别/各自”的语义等价。
- 更新提示词长度门禁与契约文档（理解 ≤2800、完整/复杂 ≤7400、简单 ≤4400）。
- 新增语义修复回归测试；`npm run check` 全量通过（1830 个测试，313 个套件）。
