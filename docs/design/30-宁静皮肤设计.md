# 30 宁静皮肤设计

> 状态：设计通过，准备实现（2026-09-17）。本设计只扩展皮肤系统，不改变业务、布局、任务、数据或安全契约；实现必须同时满足设计 27（皮肤系统）与设计 29（按需加载与目录自治）。

## 1. 范围与目标

- 新增一套按需加载的皮肤：id `serene`，显示名 `宁静`。
- 画布使用用户提供的“日出湖泊、青山、绿叶与白花”照片，资源随皮肤目录共存亡。
- 目标是安静、柔和、自然的阅读体验：低饱和湖绿与暖金日光、雾白纸面、清晰的正文与克制的古风标题。
- 不改变任何业务逻辑、根静态入口、manifest CSS 清单、切换器交互或持久化 key。

## 2. 资源与视觉

### 2.1 画布

- 资源：`styles/skins/serene/scenery.jpg`（由用户提供的 1536×1024 PNG 转换为 JPEG，质量 88，约 216 KB）。
- 铺满视口；叠加 `rgba(255,253,248,.42-.58)` 雾白罩层，保持湖泊、远山与日光的可辨识度；消息区另有中心晨雾罩层，正文使用深墨色 `#102220` 与紧凑白色光晕，保证照片上的对比度。
- 背景定位 `center 52%`，桌面与移动端均使用 `cover`；不增加背景动画。

### 2.2 色板

- 画布/雾面：`#eaf2ef`、`#f4f8f5`、`#e7f0ec`；
- 纸面：`#fffdf8`、`#f4f8f5`、`#e7f0ec`、`#ddeae5`；
- 正文：`#102220`；次级：`#344b47`；弱化：`#4f6560`；
- 主色：湖绿 `#3f827b`，悬停 `#326b65`，柔和底 `#e1f0ec`，边框 `#bcd8d2`；
- 语义色：暖赭 `#b8843f`、松绿 `#4c8465`、暮红 `#b9564e`；
- 用户气泡：晨光纸 `#f7eee0`；助手/错误气泡：暖白纸 `#fffdf8`；
- 阴影使用低饱和蓝绿灰，保持“晨雾”而非“发光卡片”。

### 2.3 表面

- 侧栏与图标栏：约 80% 透明的暖白玻璃（`rgba(255,253,248,.20)` + `blur(14px)`），背景照片明显透出，不做左侧色条；
- 输入卡、配置/确认/预览/更新日志、欢迎卡与功能卡：暖白霜纸 + 发丝边框 + 冷绿阴影；
- 思考、意图轨迹、附件 chip、引用预览、反馈字段：次级雾面；
- 消息：用户、助手与错误消息都不使用独立气泡底，文字直接落在晨雾/照片上；正文使用深墨色 + 紧凑白色光晕，行高 1.62、Markdown 1.7，保证长文阅读；
- 选中会话：湖绿约 24% 底纹 + 可见发丝边框 + 加粗标题，悬停态明显轻于选中态；重命名/删除按钮遵循全皮肤统一规则：默认隐藏，只有鼠标悬停会话标题时显示，键盘 focus、重命名态和粗指针设备保持可见。

### 2.4 排版

- 正文：`--serene-font-body`，优先 `Segoe UI Variable Text` / `Noto Sans SC` / HarmonyOS Sans SC / MiSans / PingFang SC / Microsoft YaHei UI，最后 `sans-serif`；
- 标题：`--serene-font-display`，优先 `Noto Serif SC` / Songti SC / STSong / Source Han Serif SC / Georgia / serif，呈现安静的书卷气；
- 代码：`--serene-font-mono`，Cascadia Code / JetBrains Mono / ui-monospace / Menlo / Consolas；
- 不新增网络字体、`@import` 或远程字体请求。

## 3. 加载与状态

- `client/core/skin.js` 的 `SKINS` 注册 `{ id: 'serene', label: '宁静', description: ... }`；
- `index.html` 首屏 boot 白名单增加 `serene`，未知或损坏值仍回退 `default`；
- 激活 `serene` 时仅注入一条 `/styles/skins/serene/skin.css`，并保持 default 在 bundle 内；
- 切换、刷新、localStorage 外部改写、未知 id 四路径下，DOM `data-skin`、存储值与唯一皮肤样式表三者一致；
- 切换回 default 时移除皮肤链接；不改切换器外壳。

## 4. 契约与目录

- 目录：`styles/skins/serene/`；
- 文件：`skin.css`、`scenery.jpg`；不放其他皮肤的规则或共享域规则；
- `skin.css` 三段式：
  1. 令牌段：`--skin-*`、域控制点、`--serene-*` 材质与字体令牌；
  2. 直接规则段：全部限定 `html[data-skin="serene"]`；
  3. 资产段：只用 `url("./scenery.jpg?v=1")` 相对引用；
- 禁止 `@import`、`url("../…")`、访问其他皮肤、访问服务器数据、远程字体或布局/交互覆盖；
- `styles/skin-system.css` 只增加 `.skin-swatch-serene` 色板，保持切换器外壳、菜单逻辑与皮肤数据分离；不修改 manifest。

## 5. 安全、性能与可访问性

- 图片为本地静态资源，不携带凭据、用户数据或外链；
- 不注册新的服务端路由、权限、SQL 或持久化字段；
- 不改变 CSS `!important` 棘轮基线：新增文件从 0 开始，行为性覆盖仅限视觉；
- 正文与背景保持可读对比；焦点、禁用、错误、选中状态继续使用现有语义色；
- 尊重 `prefers-reduced-motion`，皮肤本身不引入常驻动画。

## 6. 验收标准

1. `skin-core` 目录包含 `serene` 且 label 为 `宁静`；boot 白名单与注册表一致。
2. 激活 `serene` 时网络面板只新增 `/styles/skins/serene/skin.css` 与 `scenery.jpg`，default 仍在 bundle 内。
3. `serene` 的侧栏、卡片、消息、输入区、选中会话与公告/统计表面使用本文档色板；正文在桌面与移动宽度下可读。
4. 切换、刷新、外部改写、未知 id 均保持 DOM/存储/样式表一致；切回 default 不残留 `serene` 规则。
5. `skin-css-integrity` 对 `serene/skin.css` 做 UTF-8 字节级检查；目录隔离、资产存在性、无 `@import`、无路径逃逸和逐皮肤选中对比度门禁全部通过。
6. `npm run check` 全绿；专属回归测试接入 runner 与 CI。
