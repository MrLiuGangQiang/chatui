# ChatUI v1.9.3

## 新增

- 改进了模型驱动的澄清延续，因此“2”、“第二张”或“右边那只猫”等自然回复可以选择图像，而助手则继续仅询问缺少的编辑详细信息。
- 添加了 SHA-256 指纹，涵盖复制到 Docker 运行时的每个应用程序文件。
- 添加了版本、Git 提交、源指纹、脏工作空间状态和运行时模式到“/api/version”。
- 使导入忽略旧存档中的秘密，同时保留目标浏览器的现有 API 密钥和匹配的本地标头值。
- 在标签升级之前，对“main”进行精确的 Docker 运行时验证，并再次对不可变的候选版本进行验证。

## 修复

- 保持澄清识别模型驱动，具有严格的部分答案验证和一种有界模型契约修复，而不是本地关键字或序数路由。
- 使正式标签验证处理注册表传播延迟并对齐 CLI 输出，同时仍然要求每个标签解析为精确的经过验证的摘要。
- 修复了当实时消息节点保留陈旧的挂起任务所有权时，已完成的流式传输助理消息会消失，直到刷新页面为止。
- 当容器的实际运行时文件与 CI 提供的指纹不同时，使容器拒绝启动。
- 需要主 CI 来构建并启动确切的候选映像，然后验证其 API 身份、OCI 修订版、内容寻址浏览器捆绑包和关键修复。

## 删除

- 删除了秘密导出控制：备份从不包含 API 密钥、自定义标头值或生成的每个会话标头值。
- 删除了多余的配置帮助文本并加强了完整的模型配置对话框，包括提示和备份操作。

## 其他

- 更改了发布以构建一个不可变的多架构候选者，通过摘要进行验证，并将相同的摘要推广到 Docker Hub 和阿里云 ACR，而无需重建。
- 完整的项目、架构、语法、单元、回归和服务器烟雾检查。
