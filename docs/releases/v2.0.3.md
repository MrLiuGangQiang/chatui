# ChatUI v2.0.3

## 变更

- 静态资源缓存策略优化：浏览器访问应用时的 JS / CSS 资源包（bundle）在版本指纹匹配时改用长缓存（`public, max-age=31536000, immutable`），刷新或重新打开页面不再重复下载约 2.5MB 的脚本与约 500KB 的样式，加载明显更快。
- 资源包 URL 由服务端按内容哈希在每次渲染入口页时注入，版本指纹不匹配或无指纹的裸地址仍保持不缓存，服务端更新内容后浏览器自动拉取新版本，不会停留在旧版本。
- 入口页、直连模块与其他静态资源的缓存策略保持不变，聊天、生图、图片编辑、附件、意图识别等全部功能行为与上一版一致。
