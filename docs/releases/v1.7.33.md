# ChatUI v1.7.33

## 新增

- 添加了单元和服务器烟雾覆盖范围，以实现内容寻址的捆绑包修订和主页到捆绑包的一致性。

## 修复

- 现在，呈现的主页可保证每个捆绑包 URL 修订版与捆绑包 ETag 相匹配，从而防止部署后路由逻辑过时或丢失执行映射样式。

## 删除

- 无。

## 其他

- 顶级 JavaScript 和 CSS 捆绑 URL 现在使用从其捆绑源内容自动派生的修订版，从而消除了手动缓存版本同步。
- 捆绑元数据和清单缓存现在使用内容哈希，因此即使文件大小或时间戳未更改，也会检测到源更改。
- 运行“npm run check”：项目、架构、语法和所有 477 个自动化测试均已通过。
