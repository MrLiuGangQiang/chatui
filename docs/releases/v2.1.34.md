# ChatUI v2.1.34

## Changes

- 提升多个会话同时流式输出时的稳定性：浏览器按请求目标大小拆分 Chat Job SSE，单个 Job 终态不会关闭或污染其它会话。
- 修复流式恢复中的重复正文、状态-only 快照覆盖已有内容、断线后 offset 不一致和旧任务对象迟到事件污染新任务的问题。
- 为 Job SSE 增加有界写入、drain 超时、keepalive、严格订阅参数校验和优雅 shutdown 清理，降低慢客户端造成的内存/连接堆积风险。
- 修复跨上游 Buffer 边界的 UTF-8 流解析，并在上游返回损坏流事件时失败关闭，避免静默生成截断回答。
- 删除会话时补齐 image batch parent、index、child snapshot 与运行态清理，并保持现有 principal、任务和图片协议兼容。
