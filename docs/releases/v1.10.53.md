# ChatUI v1.10.53

## 修复

- 修复“继续查看输出”首次点击无法持续锚定的问题：程序触发的滚动不再被误判为手动滚动，首次点击即完成末尾定位并建立持续锚定，后续 token 会继续跟随，无需第二次点击。
- 修复流式输出中刷新页面丢失已输出内容的问题：状态文案判定收紧为仅识别应用自身的状态提示，真实回答即使包含“请稍等/已收到/已等待/正在处理”等词语，刷新恢复时也不会被覆盖成等待状态，已输出的前缀内容完整保留并继续追加。
- 修复重新生成后刷新页面导致用户与回复消息乱序的问题：含状态词语的真实回复不再在刷新时被当作状态消息丢弃，历史顺序与待定输出的占位位置保持一致。
- 为上述问题新增刷新内容完整性与消息顺序回归测试。
