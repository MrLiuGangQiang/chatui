# ChatUI v1.10.73

## Changes

- Improved image and follow-up routing so the app can automatically reconcile clear conversation evidence, resource roles, image-task continuity, and visual delivery state before execution.
- Made image-generation instructions provider-friendly: internal routing envelopes are no longer sent to the image model, and the instruction materializer receives separated resolved-task and evidence fields.
- Added a model-driven correction round when an image instruction echoes raw conversational text instead of returning one self-contained final prompt.
- Improved cancellation, idempotency, logging, and usage-request bounds for more reliable long-running jobs and busy deployments.
