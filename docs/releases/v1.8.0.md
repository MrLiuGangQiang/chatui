# ChatUI v1.8.0

## 新增

- 为目标、掩码、引用、引用的消息和历史资源添加了规范的执行资源投影和调度门。

## 修复

- 防止推断模式和资源在会话之间泄漏或污染新请求。
- 强化澄清重路由、合同修复、多图像合成和图像蒙版持久性。
- 添加了自动模式隔离、路线/资源一致性、澄清安全性、修复不变量、参考图像生成和掩模执行的回归覆盖。

## 删除

- 无。

## 其他

- 现在，在内部使用多部分图像编辑传输时，参考图像生成可以正确生成新图像。
- 围绕一个经过验证的“task_contract.v5”协议重新设计了图像、参考图像、编辑图像、视觉、文件和聊天路由。
- 自动路由现在可以选择操作、资源、API 和执行参数，而无需向用户公开内部产品模式。
- `npm run check` 通过了 518 项测试。
