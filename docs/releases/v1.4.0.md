# ChatUI v1.4.0

## 新增

- 强化了发布流程：语义标签现在可以验证存储库元数据，并在推送多架构 Docker 镜像后创建已发布的 GitHub 版本。
- 添加了可重复的工程基线：编辑器和 Git 属性、贡献指南、Node 22 固定、CI 和统一项目检查。
- 在贡献之前使用“npm run check”，在创建发布标签之前使用“npm run verify:release -- vMAJOR.MINOR.PATCH”。

## 修复

- 在服务器、Docker 映像、检查和测试中保留了“route.html”静态页面合约，以防止路由图 404 回归。
- 将大型测试入口实现移至“test/legacy/”，并将“test/run-tests.js”保留为小型稳定运行器；增加了项目合同范围。

## 删除

- 无。

## 其他

- 正式的架构、开发、测试、Docker 和发布文档。
- 现有部署无需更改应用程序配置或 API 合同。
