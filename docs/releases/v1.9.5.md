# ChatUI v1.9.5

This release fixes clarified-task continuity across regeneration, editing, and page refresh.

- Persist a versioned clarification replay record with the resolved task, confirmed supplements, selected resources, and route context.
- Reuse the complete resolved task when regenerating messages or images instead of only the final clarification reply.
- Preserve earlier confirmed clarification details when the final user reply is edited.
- Keep generated-image records stable before and after page refresh, with regression coverage for both task replay and image result identity.
