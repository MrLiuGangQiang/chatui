# ChatUI v1.6.3

## 新增

- Docker 部署可以升级到“1.6.3”或“v1.6.3”映像标签。
- 添加了生命周期、切换、重新加载、会话切换、取消、终端错误、持久性顺序和消息操作回归。

## 修复

- 通过附件捕获、路由、托管作业切换和最终会话提交，在接受发送的瞬间保持可恢复的任务所有者。
- 在页面重新加载或会话切换后恢复正在进行的工作，而无需启动重复请求。
- 在联系上游 API 之前拒绝不完整的本地作业快照，同时仅将待处理的移交与相同的完整作业和提交身份进行匹配。
- 在清除其恢复所有者之前提交最终聊天/图像结果和本地澄清响应。
- 在短暂的传输故障中保留作业，但清除终端失败的作业，这样它们就不会在每次重新加载后永远恢复。
- 在持久捕获附件数据之前发生重新加载时，处理仅附件提交和报告，而不是静默发送不完整的请求。

## 删除

- 将显式停止和会话删除视为终端，防止后期异步工作重新创建已取消或删除的任务。

## 其他

- 输出完成时同步清除流和挂起的 UI 状态，因此当后台选项卡暂停动画帧时，复制、下载、重试和相关消息按钮不再保持隐藏状态。
- 通过相同的服务器管理作业生命周期运行 GPT-5 响应推理、聊天完成、图像生成和图像编辑。
- 通过 285 项测试验证了完整的项目检查套件。
