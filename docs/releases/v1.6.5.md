# ChatUI v1.6.5

## 新增

- Docker 部署可以升级到“1.6.5”或“v1.6.5”映像标签。
- 当较旧的异步完成延迟到达时，保留较新任务的繁忙状态。
- 添加了针对浏览器用户激活行为的完成声音测试。

## 修复

- 当启动或会话恢复后挂起的作业自动恢复时，避免浏览器自动播放策略警告。
- 在共享会话任务生命周期中集中进行聊天、图像、重试、停止和恢复完​​成清理。
- 即使恢复发现已完成或已清除的作业快照，也会在完成响应后重置发送按钮。
- 仅在活动用户手势期间创建或恢复完成声音“AudioContext”。
- 添加了正常完成、恢复完成、过时繁忙状态清理和重叠任务所有权的生命周期回归。

## 删除

- 无。

## 其他

- 当用户先前解锁音频上下文时，继续播放完成声音。
- 通过 295 项测试验证了完整的项目检查套件。
