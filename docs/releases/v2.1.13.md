# ChatUI v2.1.13

本版本保持默认意图识别链路轻量，修复多行文本输入和图片交付追问的边界误判。

## 修复

- 修复“总结下面这段话”后通过换行粘贴正文时，被误判为缺少待处理文本的问题。
- 保留真正缺少正文以及下一行仍是处理要求时的澄清行为，避免把“指出问题”等后续指令误当成正文。
- 修复普通文本任务后的“结果呢”或“图片呢”可能被误归一化为图片生成任务的问题。
- 仅当前序状态明确证明存在未交付的图片生成/编辑任务时，才恢复为图片任务；普通聊天继续保持文本 follow-up。
- 默认不启用 `intent_critic` 和 `intent_reasoning`，新增回归门禁防止轻量生产链路被意外打开。

## 稳定性与质量

- 新增多行正文、普通结果追问和图片交付追问回归测试。
- `npm run check` 全量通过。
