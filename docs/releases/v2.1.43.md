# ChatUI v2.1.43

## Changes

- 新增「静谧湖晨」皮肤，加入独立的湖光画布、配色、排版和切换器样例；默认、墨色和雪山皮肤同步优化了文字可读性与对比度。
- 统一会话列表操作交互：重命名和删除按钮默认隐藏，仅在悬停会话标题时显示，同时兼顾键盘焦点、重命名状态和触屏设备；扩大标题悬停命中区域，避免操作按钮难以触发。
- 修复图片任务失败状态：将返回 2xx 但内容为空或包含错误的响应判定为终态失败，待处理卡片直接展示错误信息，并确保失败后及时释放忙碌状态。
- 修复批量图片任务清理和队列投影异常可能影响后续任务的问题；新增图片任务终态、批量清理、皮肤完整性和会话操作可见性的回归测试。
- 同步更新皮肤系统、会话列表和图片任务相关设计文档。
