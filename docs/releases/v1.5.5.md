# ChatUI v1.5.5

## 新增

- Docker 部署可以升级到“1.5.5”或“v1.5.5”映像标签。

## 修复

- 现有的 v2 快照继续正常加载，包括待处理的显示项目和最新生成的图像参考。
- 将兼容性迁移测试替换为仅当前格式的加载测试。

## 删除

- 删除了旧的每会话本地存储历史记录迁移。
- 删除了 IndexedDB 快照 v1 迁移和针对旧备份的部分历史记录协调。
- 删除了旧的显示到消息迁移 API 及其特定于恢复的帮助程序。

## 其他

- 旧的本地存储历史记录和 v1 IndexedDB 快照被有意忽略，并且不再转换或写回。
- 会话启动和实时快照重新加载现在仅接受“snapshotVersion >= 2”和有效消息列表的当前快照。
- 将静态捆绑包缓存版本提升为“1.3.105-current-snapshot-only”。
- 将会话显示模块缓存版本提升为“2.1.6-current-snapshot-only”。
- 涵盖 v2 加载、忽略旧本地存储历史记录、忽略 v1 快照和实时重新加载版本强制。
