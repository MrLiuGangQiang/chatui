# ChatUI 意图识别协议与问题反馈功能升级

为了进一步提升任务理解能力与问题排查效率，ChatUI 已完成两项重要升级。请在使用前仔细阅读以下说明。

## 一、意图识别协议升级

ChatUI 现已启用全新的意图识别协议，并引入部分特殊结构化定义，以提升复杂任务的识别准确率与执行稳定性。

目前 **DeepSeek 系列模型暂不支持部分新协议定义**，使用过程中可能出现意图识别失败、任务结构无效或请求无法正常执行等情况。为获得更稳定、完整的使用体验，建议将意图模型切换为 **GPT 系列模型**。

## 二、报错自动识别与问题反馈

ChatUI 现已增加报错自动识别功能。检测到请求异常时，系统会自动打开问题反馈界面，并填写错误信息、最近几轮会话及当前模型信息。

敏感信息会自动隐藏。请检查自动填写的内容，并补充实际期望结果后提交，帮助我们更快定位和处理问题。

感谢你的理解、配合与支持，我们将持续优化 ChatUI 的稳定性、兼容性与使用体验。
