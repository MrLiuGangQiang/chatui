# ChatUI v1.10.11

界面入口、辅助页面与长代码阅读体验优化版。

## 新增

- 长代码块支持折叠与完整展开，顶部和底部均提供双箭头控制；流式输出结束后也会自动应用相同的折叠规则。
- 新增“支持的文件”快捷入口，与“执行地图”共用无边框页面查看器，可直接查看完整说明页面。

## 优化

- “执行地图”和“支持的文件”迁移到独立 `pages/` 目录，按各自页面比例铺满查看区域；文件说明卡片统一尺寸、间距和直角底边。
- 重新设计“执行地图”“支持的文件”“使用统计”和“问题反馈”入口图标，统一按钮尺寸、对齐与蓝青紫霓虹配色。
- 执行地图第 11 步的长文字限制在卡片内容区内，不再越过容器边界。
- Docker 发布改为验证 ACR 不可变候选镜像后提升同一 digest，再同步到 Docker Hub；主分支继续通过 `Exact Docker runtime` 验证精确提交。
