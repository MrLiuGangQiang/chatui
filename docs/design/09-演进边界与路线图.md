# 09 演进边界与路线图

## 1. 已知债务（现状，不得误写为已完成）

- 根 `app.js` 仍是较大的兼容门面；工作流仍在向 `client/` 迁移。
- 部分浏览器模块仍使用受架构基线约束的 legacy `with` 注入。
- `shared/task-constants.js` 尚未进入 manifest，浏览器侧存在硬编码回退副本。
- `persistence.js` 与 `session-persistence.js` 有同名函数双实现；`escapeHtml`、job 工具等多处复制。
- `route-service.js`（约 230KB）、`route-intent-workflow.js` 等大文件待按簇拆分。
- `shared/usage/ranges.js` 仍含 server-only SQL；vendor 的来源/版本/License 未完全自动化。
- `test/legacy` 已删除；runner 与文档中的目录引用已清理。
- 皮肤视觉分层尚未完成（`docs/design/29-皮肤独立分层与按需加载设计.md`）：基础样式表 `styles.css`/`flat-theme.css`/`calm-theme.css` 仍含约 9400 个 `!important` 与大量硬编码色值，`styles/surfaces/` 已建立 `session-sidebar`、`usage-stats`、`announcement` 三个域；`skins/ink` 的生成式颜色重映射快照与逐皮肤 swatch 色板仍在，域规则的过渡期 `data-skin="default"` 前缀未摘除（29 阶段 2-3）。

## 2. 重构纪律

以上每一项必须独立立项、独立评审、带回归测试，禁止在无关功能改动中顺手重写。处理边界时同步更新 `docs/architecture.md`、本目录与 `scripts/architecture-baseline.json`（如涉及）。

## 3. 已完成基线

- 内容寻址 bundle immutable 缓存（v2.0.3）。
- 双节点意图识别与失败关闭（`docs/intent-recognition-cot-design.md`）。
- 意图识别自适应风险分层、语义覆盖审查、结构化可见轨迹和有界自修复（`docs/design/10-意图识别自适应推理与可见轨迹设计.md`）。
- 意图失败文案平实化（用户可行动）。
- 皮肤系统（默认 + 古韵 + 雪山，右下角切换并持久化，`docs/design/27-皮肤系统设计.md`）。
- 皮肤按需加载与样式分层阶段 1：bundle 只装配默认皮肤，激活皮肤由 boot 注入单条样式表，皮肤之间在结构上不可能互相影响；`styles/surfaces/` 域与控制点契约建立（`docs/design/29-皮肤独立分层与按需加载设计.md`）。
- 消息动作条文字样式与多图下载编号（`docs/design/28-消息动作条文字样式与图片下载编号设计.md`）。

## 4. 演进候选（待评估，未承诺）

- 欢迎页快捷示例、失败卡片一键重试与配置跳转。
- 会话智能标题与会话/消息搜索。
- KaTeX、emoji 等 Markdown 重资产进一步按需加载。
- 长上下文模型化摘要、暗色模式、虚拟列表开启评估。
- 发布说明旧版本归档与 legacy 引用清理。

新候选必须先形成 `NN-<功能>-设计.md`（按 00 模板），明确失败语义、契约、安全与专属回归测试后再进入实现。
