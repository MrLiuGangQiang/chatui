# ChatUI v1.9.0

## 新增

- 导入备份会替换当前浏览器的聊天记录和配置。如果仍需要现有数据，请先创建当前备份。
- 通过应用程序工作流注册表注册备份工作流，而不是添加另一个浏览器全局。

## 修复

- 将备份恢复到浏览器中，并验证支持的格式、重复会话和丢失的媒体。
- 此版本添加了便携式浏览器数据备份和恢复。

## 删除

- 无。

## 其他

- 默认排除 API 密钥、自定义标头值和会话标头值；仅通过明确的选择加入复选框来包含它们。
- 将聊天会话、模型和端点配置以及持久附件或生成的图像导出到一个 JSON 备份文件。
- 保持较旧的未标记备份和较早的便携式备份版本可导入。
