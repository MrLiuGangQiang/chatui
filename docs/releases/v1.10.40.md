# ChatUI v1.10.40

## Changes

- 聊天、意图识别、图片任务规划、文件/图片问答、后台图片标签和反馈审核等文本模型调用统一优先使用 Responses API，提高 OpenAI 兼容网关的请求与响应一致性。
- 意图识别和多图任务规划固定为一次性非流式请求，并显式发送 `stream: false`；不会把这类快速分类请求升级为 SSE。
- 对严格 JSON 输出、reasoning 参数和 Responses 兼容响应补充了受控降级与回归保护；当上游 Responses 非流式实现明确返回 `empty stream chunks` 时，仍以非流式 Chat Completions 请求兼容处理。
- 增强请求追踪、评估工具和测试覆盖，确保响应格式、资源路由和执行链路保持一致。
