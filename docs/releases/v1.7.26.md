# ChatUI v1.7.26

## 新增

- 无。

## 修复

- 网页或 HTML 修订版现在可以使用选定的历史图像作为视觉样式参考，而不会因无效聊天任务而被拒绝。
- 所选历史图像从持久存储中恢复并包含在聊天请求中，因此模型接收实际引用而不仅仅是其标识符。

## 删除

- 删除了未使用的重复 Markdown CommonJS 资源加载器。浏览器继续使用其规范的依赖项加载器。

## 其他

- 无效的意图模型输出现在被报告为模型合约失败。它不再像用户未能陈述他们的目标一样呈现，并且不会产生误导性的待澄清。
- 运行“npm run check”：项目、架构、语法和所有 441 个自动化测试均已通过。
