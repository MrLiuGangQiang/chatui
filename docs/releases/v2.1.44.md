# ChatUI v2.1.44

## Changes

- 修复模型名称在输入区显示时下伸字母被裁切的问题，例如 `qlm-flash` 现在可以完整显示。
- 修复所有皮肤输入框聚焦时的视觉跳动：聚焦现在只改变边框颜色，不再放大或加深阴影，也不改变尺寸、位置或背景。
- 默认、古韵、雪花、宁静及 Flat 主题统一使用各自的高对比强调色显示聚焦边框，解决部分皮肤聚焦反馈过弱、几乎不可见的问题。
- 新增输入框聚焦稳定性与模型名称行盒回归门禁，并同步更新输入区、皮肤系统设计文档。
