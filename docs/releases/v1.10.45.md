# ChatUI v1.10.45

## Changes

- Preserve the complete original image request as durable execution context so long follow-up edits and generations do not lose explicit constraints.
- Carry the user's original wording alongside route disambiguation instead of replacing it with a shortened route summary.
- Extend intent-routing regression coverage for deictic follow-ups, current uploads, execution-family continuity, quoted goals, strict schemas, and prompt assembly.
- Keep route-evaluation scoring compatible with the new semantic-context envelope.
- Remove redundant instruction-materialization calls for standalone new text-to-image requests, while preserving materialization for edits and resource-bound requests.
- Negotiate and reuse route-model compatibility capabilities per endpoint and model so fallback formats never reintroduce rejected parameters or repeat the retry matrix during image planning.
