# ChatUI v1.10.4

这是重置后的首份平台功能总览：以单页 Web 前端和 Node.js 代理连接任意 OpenAI 兼容服务，覆盖对话、文件、图片、任务、统计与部署。

## 功能总览

- **对话与模型**：流式/非流式聊天、停止、重试、编辑重发、复制与下载；支持聊天/路由/生图模型、自动加载、会话级覆盖、自定义模型元数据、系统与会话提示词、图片风格提示词、GPT 推理模式与 effort、思考内容展示、中文/英文输入和 IME。
- **智能路由与任务**：自动或直接选择普通聊天、文件问答、文本生图、图片编辑；路由仅接收必要文本、附件元数据和图片引用；支持澄清多轮补充、选择、重放、取消、超时、失败恢复及后台 Job 排队、运行、完成、失败、取消、恢复和事件重放。
- **图片生成与编辑**：文本生图、上传编辑、基于上一张图继续修改、多图参考/合成、遮罩、尺寸与风格；结果预览、放大、复制、下载、分享、继续编辑；图片任务可刷新恢复、停止并防重复提交。
- **附件与原生文件输入**：点击/粘贴/多选上传、进度、预览、移除、压缩、跨会话隔离和 IndexedDB 持久化；非图片文件通过 Responses `input_file.file_data` 原生发送，不调用 `/v1/files`；单文件及单次合计均小于 10 MB，校验空文件、类型、Blob、Base64 和请求体限制。
- **Markdown 与富文本**：GFM 标题、列表、任务列表、表格、引用、链接、图片、删除线、脚注、Emoji、行内代码和代码块；KaTeX 数学公式、Mermaid 图表、语法高亮、代码复制、表格横向滚动、详情折叠、图片预览和答案下载；流式输出保持未闭合结构稳定渲染并统一安全清理。
- **会话与本地数据**：多会话新建/切换/重命名/删除、草稿、标题自动生成、历史去重与规范化、滚动跟随/阅读锁定、刷新恢复未完成任务、会话备份导入导出、历史锚点、编辑替换、重新生成槽位及跨会话任务所有权校验；API Key、Header 等敏感配置不进入备份或模型上下文。
- **界面与可访问性**：会话侧栏、消息区、模型/模式控制、附件栏、输入区、任务状态区、统一提示/确认/错误 Toast、键盘焦点与 `aria-live`；适配桌面、平板和 640px 以下移动端；更新日志按需加载并支持 Markdown 与独立横向滚动。
- **统计与服务端 API**：可选 PostgreSQL 今日/昨日/总计个人统计、部门汇总、排行榜和标准 `.xlsx` 导出；提供配置/版本、模型、聊天、流式聊天、Responses Job、图片 Job、任务事件/停止/恢复、图片代理和使用统计接口；数据库未配置时核心功能不受影响。
- **安全与工程**：OpenAI 兼容代理、自定义 Base URL/API Key/Header、请求体与 Base64 校验、CORS/HTTP 方法校验、敏感日志脱敏、SSRF 私网地址拦截、受限重定向、静态资源保护；支持 Node.js、Docker、Compose、多架构 Docker Hub/ACR 镜像及固定端口健康检查，发布前执行架构/语法/单元/冒烟/Exact Docker runtime 检查。

## 支持的文件格式

- **图片**：`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`、`.svg`，以及浏览器 `image/*` MIME；JPEG/PNG/WebP 尽量压缩，BMP 转 PNG，可用于视觉聊天、图片生成参考和图片编辑。
- **PDF**：`.pdf`；使用 Responses `input_file.file_data`，支持页面清晰度 `auto`、`low`、`high`。
- **表格**：`.xls`、`.xlsx`、`.xlt`、`.xlw`、`.xla`、`.xlb`、`.xlc`、`.xlm`、`.csv`、`.tsv`、`.iif`、`.numbers`。
- **文档/富文本**：`.doc`、`.docx`、`.dot`、`.odt`、`.rtf`、`.pages`。
- **演示文稿**：`.pot`、`.ppa`、`.pps`、`.ppt`、`.pptx`、`.pwz`、`.wiz`、`.key`。
- **文本/代码**：`.asm`、`.bat`、`.c`、`.cc`、`.conf`、`.cpp`、`.css`、`.cxx`、`.def`、`.dic`、`.eml`、`.h`、`.hh`、`.htm`、`.html`、`.ics`、`.ifb`、`.in`、`.js`、`.json`、`.ksh`、`.list`、`.log`、`.markdown`、`.md`、`.mht`、`.mhtml`、`.mime`、`.mjs`、`.nws`、`.pl`、`.py`、`.rst`、`.s`、`.sql`、`.srt`、`.text`、`.txt`、`.vcf`、`.vtt`、`.xml`、`.ts`、`.tsx`、`.jsx`、`.java`、`.go`、`.rs`、`.php`、`.rb`、`.sh`、`.bash`、`.zsh`、`.tex`、`.cs`、`.scala`、`.kt`、`.kts`、`.swift`、`.lua`、`.r`、`.jl`、`.ex`、`.exs`、`.erl`、`.hrl`、`.hs`、`.clj`、`.groovy`、`.dart`、`.awk`、`.hbs`、`.mustache`、`.ejs`、`.jinja`、`.jinja2`、`.liquid`、`.erb`、`.twig`、`.pug`、`.jade`、`.cmake`、`.gradle`、`.ini`、`.properties`、`.proto`、`.scss`、`.sass`、`.less`、`.hcl`、`.tf`、`.toml`、`.graphql`、`.gql`、`.ndjson`、`.json5`、`.yaml`、`.yml`、`.astro`、`.diff`、`.patch`、`.dockerfile`；无扩展名 `Dockerfile` 按文本/代码识别。

非图片附件不会在本地提取正文；PDF 视觉页面、扫描件、图片和图表需上游模型具备视觉能力。所有文件均须小于 10 MB，单次上传合计也须小于 10 MB。
