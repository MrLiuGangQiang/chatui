# 00 设计文档索引与使用规则

> `docs/design/` 是 ChatUI 的规范层：定义定位、原则、硬约束、架构决策、契约与交付门禁。实现必须服从本目录；任何影响这些内容的变更必须同步更新本目录。

## 1. 文档体系

| 编号 | 文档 | 回答的问题 |
| --- | --- | --- |
| 01 | 设计原则与约束 | 为什么这么做？哪些是硬约束？关键决策记录 |
| 02 | 总体架构与模块边界 | 代码怎么分层？哪些依赖被禁止？核心机制是什么？ |
| 03 | 数据模型与持久化设计 | 会话、消息、图片、任务、使用统计如何存储与恢复？ |
| 04 | API 与服务契约设计 | 有哪些端点？响应、错误与缓存语义是什么？ |
| 05 | 安全设计 | 身份、任务归属、消毒、密钥与日志脱敏怎么保证？ |
| 06 | 工程规范与代码规范 | 仓库结构、编码风格、模块注册与提交规范 |
| 07 | 测试与质量门禁 | 测试分层、命名、回归门禁与 CI 接线 |
| 08 | 发布与运维设计 | 版本、发布流水线、不可变镜像、日志与 NFR |
| 09 | 演进边界与路线图 | 已知债务、重构边界与后续候选 |
| 10 | 意图识别自适应推理与可见轨迹 | 自适应推理、语义审查、自修复和用户可见轨迹 |
| 11 | 意图识别最小决策链 | 默认单任务路径、模型调用预算与失败关闭 |
| 12 | 多实例在线人数共享设计 | REDIS_URL 驱动的全局 presence 计数（按浏览器/设备去重）与跨实例广播 |
| 13 | 重新生成与编辑重发统一链路 | 消息替换/重放如何复用同一条 submit 链路 |
| 14 | 固定文件公告设计 | 如何通过固定 `announcement.md` 发布最新公告，不依赖发版 |
| 15 | 运行时推荐模型配置设计 | 如何通过运行期 JSON 文件更新推荐模型，不依赖发版 |
| 16 | 图片编辑工具设计 | 图片消息上的擦除 / 移除背景 / 评论 / 调整尺寸（见 21；后续：多轮编辑）如何实现 |
| 17 | 附件上传大小与图片压缩策略设计 | 单文件/合计 10 MB 限制、图片超过 5 MB 的自动压缩、失败提示与发送前复核如何实现 |
| 18 | 图片清晰度提升设计 | 在图片编辑工作台中一键调用 edit_image 提升细节清晰度，同时保持构图、主体和风格不变 |
| 19 | 图片编辑混合操作设计 | 评论、擦除、移除背景和画质提升如何共存为操作历史并合并为一次 edit_image 请求 |
| 20 | 图片编辑记录编辑与删除设计 | 评论如何编辑、各类操作历史如何删除，并保持编号、mask、全局参数与最终提示词一致 |
| 21 | 图片尺寸调整设计 | 如何在图片编辑工作台选择宽高比、记录输出尺寸，并在一次 edit_image 请求中生成目标画幅 |
| 22 | 网页输出渲染隔离设计 | 如何将完整 HTML/SVG 输出保留给 sandbox 预览，同时避免其 DOM 和布局进入聊天主页面 |
| 23 | 思考内容展示设计 | 思考区如何与正文区分、何时结束等待、完成后如何收起并恢复 |
| 24 | 输入区会话模型与思考强度控件设计 | 如何在发送按钮旁用一体化控件直观展示并切换当前会话模型与思考强度 |
| 25 | 流式并发、会话隔离与任务续接设计 | 200 并发下 Chat Job SSE 多路复用、背压、会话 UI 隔离与任务恢复 |
