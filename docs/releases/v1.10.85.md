# ChatUI v1.10.85

## 修复

- 消息下方的操作按钮改为随消息状态确定性地显示：消息正在输出时隐藏全部按钮；完成、手动停止或出错后全部显示；用户已发送消息的按钮始终显示。
- 修复手动停止后按钮仍被隐藏的问题：停止流程现在会清除流式与临时占位状态标记，使被停止的消息立即显示可用的复制/重新生成等操作。
- 发送的用户消息操作按钮不再只在悬停时出现，而是常驻显示在气泡下方，避免不同时机按钮不一致。

## 测试

- 新增 test/unit/message-actions-visibility.test.js 回归测试：锁定终态清理、停止流程命中流式消息，以及按钮可见性随消息状态确定性变化；旧样式下失败、新样式通过。
