# ChatUI v2.1.51

## Changes

- 上游请求现在统一携带 `User-Agent: chatui/<版本号>`（版本读取 `version.json`），覆盖 OpenAI 兼容代理、chat/image 任务、插件 HTTP/MCP、用量校验与反馈链路，便于网关与服务端识别流量来源和客户端版本。
- 用户显式配置的 `User-Agent` 自定义头保持优先，不会被覆盖；`Authorization`、`Content-Type` 与自定义头行为不变。
- 新增回归测试 `test/unit/upstream-user-agent.test.js`，覆盖代理、任务与各服务出站链路的版本标识。
