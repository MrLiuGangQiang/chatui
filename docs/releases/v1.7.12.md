# ChatUI v1.7.12

## 新增

- 添加了配额感知的完整、增量和最小回退格式，以及与最新持久快照的确定性合并。
- 为 IndexedDB 不可用的浏览器添加了立即回退持久性，并在页面离开期间限制快照刷新。

## 修复

- 添加了可恢复的 localStorage 快照回退，可保留规范历史记录​​，而不会将本地数据误报为持久 IndexedDB 提交。
- 刷新浏览器和静态捆绑缓存版本，以便部署的客户端立即收到持久性修复。
- 修复了当 IndexedDB 会话快照写入停止时，已完成的聊天响应使编写器永久陷入运行/停止状态的问题。
- 添加了对停滞数据库打开、读取和写入的回归覆盖；连接重建；重试恢复；最新修订合并；重试取消；有界冲洗；永久性存储错误；配额回退压缩；持久/后备合并；以及没有 IndexedDB 的浏览器。
- 使用注入的停止的最终快照事务验证了真实 Microsoft Edge 会话中的故障模式：完成的答案仍然可以恢复，并且在有界提交等待之后，composer 从“停止”返回到“发送”，同时 IndexedDB 恢复在后台继续进行。

## 删除

- 添加了有界 IndexedDB 打开、读取、写入、删除和清除事务，以及不健康连接重置和后期连接清理。
- 添加了自我修复的每会话快照队列，具有最新修订保留、瞬态错误重试、指数退避和删除安全取消功能。
