# ChatUI v1.10.57

## Changes

- 移除图片生成/编辑的“生成数量”参数（count/n）：单个图片任务只生成一张图，多个独立结果自动拆分为多个任务并逐张请求。
- 支持参考多张图片生成新图：多图参考直接走 gpt-image-2 生图链路，不再被误判为“多蒙版”图片编辑。
- 图片编辑仅接受一张蒙版；恢复历史任务时若发现多蒙版或绑定信息不一致，自动清理无效任务，不再反复报错或卡住。
- 修复恢复图片编辑/参考任务时图片角色映射与序列化文件身份不一致，导致“执行资源绑定失败”的问题。
- 修复历史无效图片任务恢复时反复循环的问题：静默丢弃过期任务并清理占位消息，用户可直接重新发起请求。
