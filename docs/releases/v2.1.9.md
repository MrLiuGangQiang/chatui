# ChatUI v2.1.9

ChatUI v2.1.9 加固意图路由提示词的措辞与示例，并修正意图识别评测契约对聊天类 goal 的逐字要求。

## 改进

- 意图路由提示词用「消息序号」描述候选新旧排序，不再在规则中复用 `message_index` 输入字段名，避免与「禁止输出自造字段名」的字段契约互相矛盾。
- 意图语义审查节点补充 `clarify` 与 `reject` 判定示例；多图任务规划节点补充 route_goal 只含第一步时的拆分交接示例。
- 意图识别评测契约修正：聊天类操作（`plain_chat`/`web_search`/`file_qa` 等）的执行 goal 接受用户原文或满足同一概念/禁词契约的忠实转述，不再要求逐字等于用户输入——线上聊天派发本就固定发送用户原文，路由 goal 是路由证据而非线上指令。

## 稳定性与质量

- 新增回归测试：消息序号措辞、审查判定示例、规划交接示例、聊天 goal 忠实转述契约（含无修复必失败验证）。
- 同步设计文档 5.3/5.3.1 的 provider prompt 规则描述，明确 `web_search` 归一化检索词例外。
- `npm run check` 全量通过（1842 个测试，319 个套件）。
