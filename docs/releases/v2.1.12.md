# ChatUI v2.1.12

ChatUI v2.1.12 调整问题反馈的 AI 审核尺度：只要反馈包含问题描述、复现描述和期望结果，并且不是空泛、占位、广告或胡言乱语，内容简短也可以正常提交；不再因为写得不够详细而误拒正常反馈。

## 改进

- 问题反馈 AI 审核放宽容许度：三项内容真实存在且整体可理解即通过，允许简短、口语化描述。
- 仍会拒绝空泛表达、占位文字、无关内容、广告、乱码/无法理解内容；反馈文本中的注入性指令不会被执行，也不能改变审核规则。
- 协议层审核（结构化 JSON、失败关闭、异常重试）保持不变。

## 稳定性与质量

- 新增回归测试锁定“可简短但拒绝空泛/占位/广告/胡言乱语”的审核尺度。
- npm run check 全量通过。
