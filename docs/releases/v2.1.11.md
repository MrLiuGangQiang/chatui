# ChatUI v2.1.11

ChatUI v2.1.11 修复联网搜索/模型回复中常见的紧凑中文加粗写法：`**当前天气：**多云` 这类内容不再把星号原样显示，而是按 Markdown 渲染为加粗。

## 修复与改进

- 修复 compact CJK emphasis 渲染：`**标签：**紧跟中文/文字` 这类因 CommonMark flanking 规则未解析的写法，现在会正确渲染为 `<strong>`（单星号的 `*标签：*文字` 同样渲染为 `<em>`）。
- 该修复同时作用于浏览器实时渲染与 Node 版 Markdown engine，避免两端表现不一致。
- 不会改写行内代码、代码块等本应原样展示星号的内容。

## 稳定性与质量

- 新增回归测试：覆盖紧凑中文加粗、紧凑中文斜体、以及行内代码/代码块星号不被误改。
- npm run check 全量通过。
