# ChatUI v1.5.0

## 新增

- 如果保存的会话包含旧推理首选项，请选择受支持的 GPT-5 工作值之一或在发送新请求之前关闭思考。
- 添加了聊天响应中返回的完整 HTML 文档的交互式网页预览。每个检测到的页面都有一个独立的眼睛图标预览操作和下载操作，包括包含多个页面的响应。
- OpenAI GPT-5模型的简化思维模式。该控件现在使用本机“reasoning_effort”值：“low”、“medium”、“high”、“xhigh”和“max”；思维障碍不发送任何推理参数。
- 在标签工作流程中保留发布验证：在运行完整项目检查之前验证发布元数据，然后发布 amd64/arm64 Docker 映像和 GitHub 版本。
- 更新了架构、开发、自述文件和存储库指南，以匹配简化的运行时和 GPT-5 推理行为。

## 修复

- Web 预览在第一次单击时加载，在预览框架中保留脚本、表单和链接资源，并使用无边框演示文稿。浏览器资产缓存版本已更新，因此部署的客户端会立即收到修复。
- 升级后部署应刷新浏览器资产；新发布的缓存版本会自动处理正常刷新。
- 添加了针对 Web 预览检测、多页面操作、首次打开行为、无边界 iframe 样式和推理兼容性清理的回归覆盖。

## 删除

- 删除了过时的多提供商思维兼容性、令牌预算映射、静默推理降级重试以及未使用的托管访问令牌配置。
- 简化了服务器运行时接线并删除了不再属于产品流程一部分的冗余兼容性模块、检查和所有权/身份验证脚手架。
- 现有的托管访问令牌值不再使用，并且可能会从部署配置中删除。

## 其他

- 无需数据迁移。
