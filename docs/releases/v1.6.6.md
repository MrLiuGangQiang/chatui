# ChatUI v1.6.6

## 新增

- Docker 部署可以升级到“1.6.6”或“v1.6.6”映像标签。
- 将聊天作业标识符的创建与瞬态消息显示记录和过时的本地模型检查分离。

## 修复

- 确保在聊天时重新分类的已编辑图像任务收到新的持久聊天恢复标识符。
- 修复了将编辑的消息路由到图像生成时可能出现的 JavaScript 临时死区错误。
- 当浏览器 IndexedDB、待提交数据或瞬态显示状态已被清除时，创建新的客户端聊天作业标识符，而不是因恢复标识符错误而失败。
- 更改浏览器资源缓存版本，以便客户端加载修复后的提交和图像工作流程。
- 添加了图像生成变量阴影、图像到聊天重新路由和缺少本地恢复状态的回归覆盖。

## 删除

- 无。

## 其他

- 使根后备提交工作流程与模块化浏览器工作流程保持一致。
- 通过 318 项测试验证了完整的项目检查套件。
