# ChatUI v2.1.26

## Changes

- 图片编辑器新增“调整尺寸”，支持方形 1:1、竖版 3:4、故事版 9:16、横版 4:3 和宽屏 16:9，并复用现有图片编辑链路生成目标画幅。
- 图片编辑器操作文案统一为“标记评论 / 背景移除 / 画质提升 / 局部擦除 / 调整尺寸”，提交按钮改为“提交修改”，右侧面板改为“操作历史”。
- “标记评论”工具栏图标与激活后的十字准星光标保持一致。
- 评论编辑框改为紧凑自动高度，多行内容可内部滚动；左右面板和底部操作栏会跟随图片显示高度整体居中。

## Verification

- `npm.cmd run check`：项目、架构、语法检查及 1986 个测试全部通过。
