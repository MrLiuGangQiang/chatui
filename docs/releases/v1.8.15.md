# ChatUI v1.8.15

This hotfix improves production Docker deployments and response persistence.

- Preserve explicit `CHATUI_ALLOWED_ORIGINS` behavior behind TLS-terminating reverse proxies.
- Replace an older assistant response when a newer regenerate result targets the same canonical slot.
- Keep stale or empty background snapshots from overwriting committed responses.
- Make the first session-switch interaction reliable while another session has a running task.
- Add regression coverage for configured Origin requests and regenerated response persistence.
