# ChatUI 使用说明与模型配置建议

ChatUI 是一款面向日常 **轻量级聊天与生图** 的个人工具。服务器不会保存你的会话或附件数据，相关数据仅保存在当前浏览器本地。请妥善管理自己的数据；如需迁移或备份，可使用“设置”中的导入、导出功能。

## 设计目的

1. **降低使用门槛**：方便使用各类模型，无需为使用海外模型额外处理网络问题。
2. **减少 Token 消耗**：ChatUI 会根据任务意图自动选择最合适的上下文，并以最小必要输入执行任务。相较于 WorkBuddy、Codex、Claude、Claw 等工具的全量上下文方式，典型场景下可节省 **90% 以上** Token。
3. **辅助了解使用情况**：集成常用统计功能，帮助你查看自己的使用情况。

## 反馈与边界

本项目为个人作品，测试与维护精力有限。若你的使用场景尚未被覆盖，欢迎通过右上角“反馈”提交问题和建议。

## 模型兼容性与推荐配置

- **不要将 DeepSeek 用作意图识别模型**：ChatUI 的意图识别请求使用了 `response_format`，DeepSeek 目前不支持该能力，可能导致意图识别失败。
- **图片理解、识图和读文件请使用 GPT 系列聊天模型**：DeepSeek 目前不支持多模态能力；GPT 全系列支持多模态。
- 一般建议：
  - 意图模型：`gpt-5.6-terra`
  - 聊天模型：`gpt-5.6-terra`
  - 涉及复杂问题时：意图模型也可切换为 `gpt-5.6-terra`

感谢你的理解、使用与反馈。
