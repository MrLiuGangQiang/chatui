# ChatUI v1.9.3

## Reliable streaming and clarification

- Fixed completed streamed assistant messages disappearing until the page was refreshed when a live message node retained stale pending-task ownership.
- Improved model-driven clarification continuation so natural replies such as `2`, `第二张`, or `右边那只猫` can select an image while the assistant continues asking only for missing edit details.
- Kept clarification recognition model-driven, with strict partial-answer validation and one bounded model-contract repair instead of local keyword or ordinal routing.

## Source-to-image release integrity

- Added a SHA-256 fingerprint covering every application file copied into the Docker runtime.
- Added version, Git commit, source fingerprint, dirty-workspace state, and runtime mode to `/api/version`.
- Made containers refuse startup when their actual runtime files differ from the fingerprint supplied by CI.
- Required main CI to build and start the exact candidate image, then verify its API identity, OCI revision, content-addressed browser bundle, and critical fixes.
- Changed publication to build one immutable multi-architecture candidate, verify it by digest, and promote that same digest to Docker Hub and Alibaba Cloud ACR without rebuilding.
- Made formal-tag verification handle registry propagation delay and aligned CLI output while still requiring every tag to resolve to the exact verified digest.

## Verification

- Full project, architecture, syntax, unit, regression, and server smoke checks.
- Exact Docker runtime verification on `main` and again on the immutable release candidate before tag promotion.
