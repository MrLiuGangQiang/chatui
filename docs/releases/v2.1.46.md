# ChatUI v2.1.46

## Changes

- 优化“重新生成”和“编辑重发”：开始重新执行前会清理原轮次中的旧回答、错误提示和旧图片结果，避免残留内容与新结果混在一起；后续对话仍会完整保留。
- 多任务澄清回答支持“第二个吧”“就第二个”等自然编号选择；无法唯一确定任务时直接提示有效编号，不会误执行其他任务。
- 统一意图识别规则与实际执行合同：修正证据路径、任务选择和关联判定；图片对比固定要求恰好两张图片，额外图片不会在未提示的情况下被静默忽略。
- 同步更新意图识别和重新生成链路设计说明，并为上述行为补充回归门禁。
