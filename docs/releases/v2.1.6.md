# ChatUI v2.1.6

ChatUI v2.1.6 优化意图识别的证据优先级，新增显式联网查找与意图语义审查，并加强图片指令的引用校验。

## 新增

- 显式联网查找：“查查最新信息”“最新新闻”“check the latest news”等请求现在会路由到 web_search 并启用检索工具；针对本地文件/图片的“查一下”表述不会误触发联网。
- 意图语义审查节点：路由结果交付前会按证据优先级检查动作覆盖、资源角色、relation 与 goal_mode，缺少关键要求时澄清或定向修复，而不是把冲突结果直接发给执行模型。

## 改进

- 意图理解结果只作为低优先级证据，当前输入与当前附件始终优先，减少历史图片/文字导致的误判；复杂路径与完整路由规则集保持一致。
- 图片指令物化边界加强：“与之前的猫的插画保持一致”“最近生成的那张”等跨轮风格/一致性引用会被识别为未解析，不再透传给图片模型猜测。
- 引用消息按证据优先级处理：当前输入已明确的要求优先，引用只作为补充背景。
- 路由模型调用次数耗尽后重置计数，重试不再被上次预算卡住。

## 稳定性与质量

- 更新提示词长度门禁与契约文档（理解 ≤2600、完整/复杂 ≤6400、简单 ≤4000）。
- 新增并更新路由提示词、web_search、引用与图片指令等回归测试；`npm run check` 全量通过（1824 个测试，313 个套件）。
