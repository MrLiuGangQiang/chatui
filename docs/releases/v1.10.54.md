# ChatUI v1.10.54

## 修复

- 修复意图识别在严格结构化输出（strict json_schema）下返回 HTTP 400 的问题：不再把用户本轮输入作为 goal 的 enum 字符串字面量写入请求 schema，wire 上的 goal 保持为普通字符串；goal 的非空、长度上限与精确输入规则改由本地校验和编译边界强制，避免部分网关拒绝用户派生的长字面量。
- 严格结构化输出 schema 清洗器同步移除 const、minimum、maximum、multipleOf、exclusiveMinimum、exclusiveMaximum 等不在严格子集内的关键字，图片规划等协议保持本地校验兜底。
- 新增长输入不再生成 goal 字面量、以及严格 schema 清洗范围的回归测试；意图路由评估基线 53/53 通过。
