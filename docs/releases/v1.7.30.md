# ChatUI v1.7.30

## Reliability improvements

- Browser runtime scripts and styles now revalidate after deployment, preventing a new page shell from running with stale cached workflow modules.
- First-pass task routing now explicitly requires every `task_contract.v3` field, including empty directive arrays such as `constraints: []`, so normal requests complete in one routing call.
