# ChatUI v2.1.10

ChatUI v2.1.10 让生图提示词优先使用你的原始完整描述，不再因路由/物化改写而静默丢失细节；同时修复图片结果实时完成时操作按钮的即时可用性。

## 修复与改进

- 直接生图细节保真：自足的新生图请求（text_to_image + new + replace、无引用/无绑定）以你的原始完整输入作为最终执行提示词；路由模型 goal 只作为识别元数据（userGoal），不再用浓缩改写替换原文。
- 移除意图路由 goal 的 1000 字符静默截断：goal 本地上限与 task continuity 渲染上限对齐为 16000，长提示词不再被静默截断；超过上限的输出仍按无效模型输出失败关闭。
- 图片指令物化保留用户细节：整理/改写允许消解指代并补充自足表述，但必须完整保留 current_input 中用户明确写出的对象、数量、顺序、否定/排除与细节，禁止为去重删除用户细节。
- 图片结果实时完成时同步把生成图片操作按钮挂到消息操作栏，避免实时完成态缺少可用的图片操作。
- 同步架构、意图最小决策链、意图识别 CoT 与手动验收文档。

## 稳定性与质量

- 新增回归测试：长于旧 1000 字上限的直接生图原文完整进入最终执行 prompt（模型短 goal 不得替换执行文本）；忠实长 goal（超过 1000 字）合法且完整执行。
- 新增图片操作按钮实时 hydration 回归测试。
- npm run check 全量通过（1844 个测试，319 个套件）。
