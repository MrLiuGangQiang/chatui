# ChatUI v1.10.19

异常反馈自动化增强版：遇到异常时自动整理诊断信息与最近会话，降低问题复现和反馈成本。

## Changes

- 浏览器检测到网络失败、非 2xx 响应、未捕获异常、未处理 Promise 拒绝或资源加载失败后，会等待 5 秒再自动打开问题反馈窗口，避免打断瞬时恢复流程。
- 自动在反馈表单中填写脱敏后的异常时间、请求路径、响应状态，并附带当前会话最近 3 轮用户消息与助手答复。
- API Key、Bearer Token、密码、URL 查询参数、Base64 文件数据和临时 Blob 地址不会写入自动反馈内容。
- 反馈草稿在窗口关闭后继续保留，同一标签页重新打开或刷新后仍可恢复；仅在反馈成功提交后清除。
- 主动停止请求和反馈接口自身失败不会递归触发新的反馈窗口，短时间重复异常会自动去重。
