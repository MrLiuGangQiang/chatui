# ChatUI v2.1.28

## Changes

- 完善网页输出隔离：同一回答中的多个网页分别生成代码块，网页之间的说明文字和尾部 Markdown 不再被错误吞入代码块。
- 未变化的网页预览卡片不再重复删除和重建，减少流式更新与长会话中的冗余 DOM 操作。
- 全屏图片预览的“编辑”按钮同时处理 Promise 失败和同步异常，任何打开失败都会恢复按钮和预览状态，不需要刷新页面。
- “调整尺寸”菜单支持方向键、Home/End 和 Escape，并统一为轻量蓝色键盘焦点样式。

## Verification

- `npm.cmd run check`：项目、架构、语法检查及 1997 个测试全部通过。
- 已使用本机 Headless Edge 完成桌面和窄屏截图评审，覆盖图片编辑器、尺寸菜单、网页输出、网页预览和全屏图片预览编辑入口。
