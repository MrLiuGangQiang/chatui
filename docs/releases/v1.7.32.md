# ChatUI v1.7.32

## Fixes

- Resource-free `plain_chat` follow-ups, corrections, and continuations now remain valid standalone conversations instead of triggering a redundant route repair or fallback request.
- Historical or quoted message/media bindings still require an explicit patch baseline, preserving strict resource safety for executable operations.
- The execution waiting map is included with its cache-busted formatting script and root stylesheet so the five-step progress display is available after deployment.
