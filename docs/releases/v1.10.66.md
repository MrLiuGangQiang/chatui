# ChatUI v1.10.66

## Changes

- Fix multi-image plan execution when several child tasks reuse the same historical image: the batch parent now restores the resources authorized by its executable child contracts and deduplicates shared media before projection.
- Keep distinct child image and file bindings resolvable during batch submission instead of treating the planning-only parent as the execution resource source.
- When an undelivered pending submission is discarded during recovery, commit a terminal failed task state so the composer leaves stop mode and becomes submit-ready without manual cancellation.
- Add regression coverage for shared historical image recovery in `image_plan.v1` batches and stale task-lifecycle cleanup.
