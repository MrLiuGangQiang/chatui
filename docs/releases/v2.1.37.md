# ChatUI v2.1.37

## Changes

- 修复刷新或切换会话后，正在输出思考内容的任务只显示思考首段、后续思考不再续接的问题；正文和思考继续共用同一流式恢复入口。
- 修复刷新恢复时服务端 Job 已不存在仍反复请求并产生 404 的问题，同时清理残留 pending 投影。
- 强化停止任务：停止请求使用 keepalive，精确取消对应 Job；服务端拒绝停止时提示重试并保留恢复指针，停止后不再渲染迟到更新。
- 将上游超时改为有效输出空闲超时：正文或思考增量会续期，流中途持续静默会中止，heartbeat 和空事件不会无限续期。
- 将运行中任务的 pending 持久化改为有界恢复游标，降低多会话长输出时的页面卡顿、存储配额和 IndexedDB 排队问题。
- 公告更新改为 SSE 推送，在线页面无需刷新即可看到新公告。
- 优化长流式输出的 DOM 更新、节点查找、任务位置复用和重新生成等待停止状态。
