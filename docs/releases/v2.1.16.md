# ChatUI v2.1.16

## 新增

- 公告改为运行目录内的固定文件 `announcement.md`，保存后刷新页面即可更新，不再依赖发版。
- 新增运行期推荐模型配置 `model-recommendation.json`，统一驱动公告侧栏和新会话欢迎页的推荐模型展示。
- 公告内容变化会自动生成新的阅读标识，并重新触发未读提醒。

## 变更

- `/api/announcements` 只返回固定文件中的当前公告，不再展示历史公告。
- 旧 `docs/announcements` 不再进入接口、Docker 镜像或运行指纹。
- 推荐模型配置通过 `/api/config/public` 下发；文件缺失或格式错误时继续使用内置推荐值。

## 修复

- 修复推荐模型配置文件更新后，前端未实际应用新值的问题。
- 修复公告确认按钮在未显示历史公告时未靠右对齐的问题。

## 部署

Docker 部署时将公告与推荐模型目录只读挂载到 `/app/data/announcements`：

```bash
-v /宿主机目录:/app/data/announcements:ro
```
