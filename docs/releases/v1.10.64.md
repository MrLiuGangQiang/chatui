# ChatUI v1.10.64

## Changes

- Fix intent recognition timeouts ("本次未执行：意图识别超时") on reasoning models: intent recognition, image-instruction materialization, and image planning now explicitly request no model thinking (reasoning effort `none`), so DeepSeek V4 and GPT reasoning models answer within the intent deadline instead of spending it on hidden reasoning.
- Keep the no-thinking directive on the Chat Completions compatibility path and automatically strip it with a retry for gateways that reject reasoning parameters.
- Speed up page loads and API requests: the index page and asset bundles no longer re-scan every static file per request, and job/idempotency lookups no longer sweep their whole tables on every read.
- Close a job-lifecycle gap: when a running chat or image job is evicted (running timeout or job-limit bound), it now ends in a terminal error state and live progress subscribers are notified immediately instead of hanging until the next poll.
- Remove a dead upload-progress helper whose timer had no cleanup path.
