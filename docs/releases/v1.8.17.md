# ChatUI v1.8.17

## 新增

- 无。

## 修复

- 保留 v1.8.7 消息替换、会话持久性、图像编辑恢复、附件提取和上游安全行为。
- 在解析代理流时正确保留分割的 UTF-8 字符，并安全地拒绝格式错误的编码作业 ID。
- 此稳定性版本恢复了经过验证的 v1.8.7 应用程序基线，并仅保留经过严格验证的修复程序。
- 当另一个会话有正在运行的任务时，确保第一个鼠标或笔会话切换可靠。

## 删除

- 删除 v1.8.7 后的 Origin 限制、并发快照合并、超大 SSE 事件限制以及相关的运行时重写。

## 其他

- 保持 Docker 发布受限，而无需导出先前停止发布的工作流缓存。
