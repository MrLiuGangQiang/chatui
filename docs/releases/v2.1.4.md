# ChatUI v2.1.4

ChatUI v2.1.4 把「重新生成」和「编辑重发」收敛为同一条提交链路，避免两套重复实现继续漂移。

## 消息替换统一链路

- 重新生成不再独立复制路由、资源池、图片/批量/聊天执行和任务生命周期，改为复用编辑重发的 `runSubmit`：重新生成使用原消息原文，编辑重发使用修改后的文本，其余处理完全一致。
- 重新生成只负责解析前一条用户消息、恢复原附件，并准备相同的编辑状态后调用统一提交入口。
- 保留待处理澄清重放与强制生图入口。

## 清理与稳定性

- 删除旧重新生成实现遗留的截断/投影逻辑及不再使用的依赖注入，避免后续被误恢复。
- 新增回归门禁：旧 `truncateRegenerationBranch`、独立路由和独立批量发送等废弃实现重新出现时测试会失败。
- 图片重新生成统一使用 canonical dispatch prompt，不再出现原文与解析指令重复拼接。
- `npm run check` 全量通过（1795 个测试，313 个套件）。
