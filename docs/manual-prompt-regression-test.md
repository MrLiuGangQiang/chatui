## 16. 图片编辑指令的接口视角（provider 只收到指令文本+绑定输入图）

> 根因修复：指令物化提示词改为"站在接口视角写"——接口只收到这段指令文本和绑定的输入图，
> 任何"最近生成的那张/上一张图/上次画的"等会话定位语在接口视角都不存在；编辑目标图已绑定，
> 应直接写"这张图"或具体内容描述。校验层新增结构化"轮次定位+生成/编辑动词"规则类拒绝此类措辞。
> 物化指令形态按目标拆分：edit_image（无论 goal_mode）、image_reference_gen 与 text_to_image+replace
> 输出完整自足指令；text_to_image+amend 只输出本轮增量，基础由下游任务连续性协议拼回，不得重复基础。
> 委托创作自由（“随便/你决定/you choose/up to you”）或澄清已回答（answer_complete=true）时允许自选具体细节，
> 但输出形态仍按上述拆分执行：text_to_image+amend 仍只写增量，不得输出完整自足指令。

| # | 前置 | 输入 | 预期最终发给生图/编辑接口的指令 |
|---|---|---|---|
| 16.1 | 生成一张猫的插画后 | 把最近生成的那张猫插画的背景换成雪山前的草地 | "在这张猫的插画的基础上，将背景替换为雪山前的草地场景。保持猫的主体形象、姿态、表情和插画风格不变。"（不得出现"最近生成/上一张"） |
| 16.2 | 生成两张图后 | 把上一张图改成黑白 | "把这张图改成黑白"（不得出现"上一张"） |
| 16.3 | 生成猫图后 | 上次画的猫换成黑色背景 | "把这张猫的图换成黑色背景"（不得出现"上次画"） |
| 16.4 | 参考图生成后 | 用刚才那张参考图的配色生成海报 | "参考这张图的配色生成海报"（绑定的参考图写"参考图"，不写"刚才"） |
| 16.5 | 生成猫图后 | 不要用最近生成的那张图，重新画一只狗 | 正常生成新图（否定语不影响执行，不发旧图作参考） |
| 16.6 | 生成图后（指令物化失败场景） | 同 16.1 | 若物化模型仍输出"最近生成"，应被拒绝并重写一轮；重写仍不合格则停止执行 |
| 16.7 | 户型任务存在前序基础（task_state） | 在原有基础上把堂屋改到中央 | 物化指令只写增量（"把堂屋改到中央"），最终 provider prompt = 基础要求 + 修订要求（仅增量），不得重复基础 |
| 16.8 | 户型任务存在前序基础（task_state）且用户委托创作自由 | 随便改一下 | 物化指令仍只写增量，最终 provider prompt = 基础 + 增量，不得复述基础；不得再追问已委托细节 |
