# ChatUI v1.10.46

## Changes

- Attachment-only requests now deterministically analyze every supported image and file submitted in the current turn, so route-model output cannot silently omit uploaded inputs.
- Make interrupted submission recovery safer: only a matching server-persisted job handoff resumes after reload; incomplete client-side routing work is cleared instead of being replayed.
- Add safe request-stage audit fields for intent recognition, image-instruction preparation, and final execution, while keeping prompts and credentials out of access logs; full request-trace text remains opt-in.
