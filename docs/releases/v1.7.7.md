# ChatUI v1.7.7

## 新增

- 为低分辨率桌面显示器添加了高度感知的欢迎页面布局。
- 为极短的桌面视口添加了超密集后备。
- 添加了足够的移动滚动间隙，以便使用通知可以完全移动到作曲家上方。
- 确认呈现的欢迎标题与预期的中文产品名称匹配，并且不包含替换的问号序列。

## 修复

- 将欢迎副本保留为 ASCII 安全 JavaScript Unicode 转义，以避免 Windows 工具上的编码丢失。
- 无论何时合适，都将欢迎内容保持在视觉上居中，同时在固定作曲家上方保留安全空间。
- 防止创作者在常见的 1366x768、1024x600 和 800x600 显示器上剪切或覆盖欢迎页面。

## 删除

- 无。

## 其他

- 发布于 2026 年 7 月 20 日。
- 刷新了应用程序和静态捆绑包缓存版本，以便浏览器不会重复使用旧的损坏的欢迎脚本，该脚本将中文文本呈现为问号。
- 验证了 Microsoft Edge 中 1366x768、1280x720、1024x768、1024x600、800x600、761x500、390x844 和 360x640 的欢迎布局。
- `npm run check` 通过了 371 项测试。
