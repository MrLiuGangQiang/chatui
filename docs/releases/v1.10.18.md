# ChatUI v1.10.18

路由与请求处理重构版：移除自定义 Header 参数，整理浏览器模块边界。

## Changes

- 移除配置弹窗中的自定义 Header 参数功能；历史版本写入的 `headerParams` 不再参与请求，普通配置保存也不会保留这些兼容字段。
- 路由意图识别拆分为候选目录、payload、决策编译、修复策略与执行门禁等独立模块，路由结果仍为可验证的 canonical decision，对外行为保持一致。
- Markdown 渲染与安全过滤抽成 Node/Browser 共用原语和统一白名单，任务列表、表格对齐、KaTeX/Mermaid 等现有能力不受影响。
- 会话快照的降级存储与配额恢复逻辑抽为独立模块，会话恢复行为保持不变。
- 生产依赖收敛为服务端运行所需（jszip、pg、undici），Markdown/测试相关依赖移至开发依赖；要求 Node >=20.19.0。
- 静态服务与 bundle 服务的路径穿越校验与内容哈希统一到 `server/http/static-path-utils.js`。
