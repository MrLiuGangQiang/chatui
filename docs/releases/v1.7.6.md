# ChatUI v1.7.6

## 新增

- 添加了针对 Windows、macOS、iPhone/iPad 平台检测、主动组合、旧键代码 229 和绑定 DOM 事件行为的单独回归覆盖。

## 修复

- 修复了间歇性 Windows 行为，其中 Enter 插入换行符，而不是在 IME 组合结束后立即发送。
- 将组合后尾随 Enter 解决方法限制为 Apple 平台，而不是在全球范围内应用 macOS Safari 解决方法。
- 保留 macOS IME 候选确认，不会意外发送，同时防止抑制的尾随 Enter 插入换行符。

## 删除

- 无。

## 其他

- 发布于 2026 年 7 月 20 日。
- 仅消耗了一个 Apple 尾随 Enter，因此下一个故意 Enter 可以正常发送。
- 在 Windows 上的 Microsoft Edge 中进行了验证，在合成过程中 Enter 不会提交，并且“compositionend”之后立即 Enter 会阻止文本区域换行并仅提交一次。
- `npm run check` 通过了 371 项测试。
