# ChatUI v1.6.0

## 新增

- 仅当任务契约明确标识时，才允许后续、更正和继续请求保留先前的上下文。
- Docker 部署可以升级到“1.6.0”或“v1.6.0”映像标签。
- 用一种规范的“task_contract.v2”协议替换了传统的混合路由格式，用于分类、审查、澄清和执行计划。
- 添加了重点任务上下文边界测试并更新了路由、浏览器契约和回归覆盖范围。

## 修复

- 防止新的图像请求继承先前任务中不相关的提示或历史图像资源。
- 拒绝遗留路由对象，而不是默默地适应不明确的模型输出。

## 删除

- 删除了重复的路由决策模块，并在“docs/architecture.md”中记录了单合约边界。

## 其他

- 在将意图、任务关系、执行操作、资源、提示计划和澄清状态投影到现有浏览器工作流程中之前对其进行验证。
- 保持图像编辑上下文回退，同时将其与新图像生成请求分开。
- 在发布前验证了完整的项目检查套件。
