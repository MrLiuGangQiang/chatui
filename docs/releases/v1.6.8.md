# ChatUI v1.6.8

## 新增

- Docker 部署可以升级到“1.6.8”或“v1.6.8”映像标签。
- 添加了空白显示索引、跨模式规范消息索引和规范之前 DOM 提交排序的回归覆盖。

## 修复

- 使用一种受保护的显示顺序插入方法，因此空白或无效索引无法再将新消息移动到历史记录的开头或可见尾部之外。
- 修复了新发送的消息已成功保留但在刷新之前不会立即显示在当前页面中的问题。
- 在渲染 DOM 投影之前写入规范消息状态，防止渲染和虚拟化代码观察到不完整的提交。

## 删除

- 无。

## 其他

- 在聊天、图像生成和图像编辑模式中为用户消息分配规范顺序索引，而不是将图像模式索引留空。
- 在真实浏览器中验证连续图像模式提交；第二条消息立即出现在对话尾部，无需刷新。
- 通过 328 项测试验证了完整的项目检查套件。
