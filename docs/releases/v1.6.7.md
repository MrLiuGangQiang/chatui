# ChatUI v1.6.7

## 新增

- Docker 部署可以升级到“1.6.7”或“v1.6.7”映像标签。
- 加载具有不完整索引元数据的旧会话快照时，保留每个现有的问答对。
- 使用一种规范的回合替换路径进行消息编辑、答案重新生成和强制图像生成。
- 创建丢失的助理替换槽位，而不覆盖下一个用户问题。

## 修复

- 防止缺少索引的挂起恢复记录声明或覆盖对话中的第一条消息。
- 确保编辑始终替换所选问题及其原始答案，无论当前路线是聊天、图像生成还是图像编辑。
- 在路由之前保留编辑目标和编辑的规范历史记录​​，因此刷新和恢复不会附加第二个问答组。
- 将重复的恢复节点协调回原始答案位置，而不是在最后显示额外的答案。
- 添加了对遗留空白索引、待提交索引恢复、规范替换槽和重复 DOM 协调的回归覆盖。
- 通过浏览器级恢复检查验证正常编辑、图像模式处于活动状态时的编辑以及编辑路由期间的刷新。

## 删除

- 修复了空白或丢失的消息索引被解释为索引零的问题，这可能会在历史压缩期间重新排序对话或删除消息。

## 其他

- 通过 326 项测试验证了完整的项目检查套件。
