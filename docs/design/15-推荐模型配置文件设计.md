# 15 运行时推荐模型配置设计

> 状态：与公告目录发布一起实施  
> 日期：2026-09-10

## 1. 范围与目标

在已有运行期公告目录中增加一个固定 JSON 文件，用于维护公告侧栏和欢迎页展示的推荐模型配置：

- 不修改代码、不发版即可更新推荐模型；
- 服务端每次请求 `/api/config/public` 时读取文件；
- 前端使用接口返回值更新公告侧栏和欢迎页；
- 文件缺失、格式错误或字段为空时，回落到当前内置推荐值；
- 不修改用户已保存的模型选择，只更新“推荐展示”。

非目标：

- 不自动保存或覆盖用户的 API Key、聊天模型、意图模型和生图模型；
- 不新增数据库、后台页面、登录或审批；
- 不改变模型调用、路由和执行合同。

## 2. 文件

运行期文件：

```text
data/announcements/model-recommendation.json
```

文件内容：

```json
{
  "route_model": "gpt-6-astra",
  "chat_model": "gpt-6-astra",
  "image_model": "gpt-image-2",
  "note": "处理文档、联网搜索请使用 GPT 系列。"
}
```

字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `route_model` | 否 | 意图识别推荐模型 |
| `chat_model` | 否 | 聊天推荐模型 |
| `image_model` | 否 | 生图推荐模型 |
| `note` | 否 | 欢迎页推荐说明，可留空使用内置说明 |

该文件同时作为镜像默认值；Docker 挂载目录中的同名文件会覆盖它。

## 3. 服务端契约

`GET /api/config/public` 的 `config` 增加：

```json
{
  "modelRecommendation": {
    "routeModel": "gpt-6-astra",
    "chatModel": "gpt-6-astra",
    "imageModel": "gpt-image-2",
    "note": "处理文档、联网搜索请使用 GPT 系列。"
  }
}
```

读取规则：

- 文件路径为 `CHATUI_ANNOUNCEMENTS_DIR/model-recommendation.json`；
- 每次请求都读取文件，响应保持 `no-store`；
- 文件最大 64 KiB；
- 模型名最多 120 个字符，`note` 最多 300 个字符；
- 去掉控制字符和首尾空白；
- 缺失字段使用内置默认值；
- JSON 无效、文件不可读或字段非法时整体回落到内置默认值，不能阻塞主应用。

内置默认值与当前页面一致：

```json
{
  "routeModel": "gpt-6-astra",
  "chatModel": "gpt-6-astra",
  "imageModel": "gpt-image-2",
  "note": "处理文档、联网搜索请使用 GPT 系列。"
}
```

## 4. 前端行为

前端在现有 `/api/config/public` 加载流程中读取 `modelRecommendation`，并更新：

1. 公告侧栏“推荐模型配置”的三个值；
2. 新会话欢迎页的推荐模型说明。

静态 HTML 和 `app.js` 中的原推荐值保留为无接口/接口失败时的兜底。用户保存的模型配置不变。

## 5. 安全与缓存

- 文件与公告目录使用同一只读挂载，不进入 `/data/` 静态路径。
- 推荐文件不得包含 API Key、数据库连接串或其他凭据。
- `/api/config/public` 保持 `no-store`，文件更新后刷新页面即可看到。
- 不在日志中记录文件全文或用户配置。

## 6. 验收标准

1. 创建或修改 `data/announcements/model-recommendation.json` 后，刷新页面，公告侧栏和欢迎页显示新推荐值。
2. 文件不存在时，页面继续显示当前内置推荐值。
3. 文件 JSON 非法时，页面不报错并回落到内置推荐值。
4. 修改推荐文件不需要改代码、重启服务或发版。
5. 不覆盖或清空用户已保存的模型配置。
