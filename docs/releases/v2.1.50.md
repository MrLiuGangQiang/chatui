# ChatUI v2.1.50

ChatUI v2.1.50 修复了同一会话中的追问被意图路由误判为新任务后丢失全部上下文的问题；现在普通聊天即使被路由判为新任务，也会保留窗口内会话历史。

## 聊天上下文连续性修复

- 普通聊天（`plain_chat`）改为会话型执行策略：同一会话内即使路由判定 `relation=new`，最终请求仍携带窗口内完整会话历史；只有用户显式引用某条消息时才使用 `bound_only`。路由再误判"新任务"，也不会让模型失忆。
- 图片、文件、联网检索等证据型任务的新任务仍保持干净起点（`history=none`），不携带无关会话历史。
- 路由提示词（FULL/SIMPLE）规则 4 新增校准：无法确定是否独立新主题时不得选 `new`，按规则 3 选 `followup`，从源头降低误判概率。`relation` 仍完全由模型裁决，未引入本地关键词改写，失败关闭策略不变。
- 提示词同步做等义压缩，保持既有长度门禁（FULL/COMPACT ≤7600，SIMPLE ≤4500）。
