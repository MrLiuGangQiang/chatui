# ChatUI v1.8.2

## 新增

- 当需要先前的文本时，保留明确引用的描述和真正不完整的后续内容。
- 添加了对不明确的编辑目标和缺少编辑详细信息的说明，而无需默默选择图像或调用后备路由。
- 扩展了路由、契约、澄清、上下文边界和表示回归覆盖范围。

## 修复

- 无。

## 删除

- 用紧凑编号的候选缩略图替换了不可读的图像选择文本，并删除了不受支持的“所有图像”选项。

## 其他

- 将紧凑的语义路由决策编译到经过验证的执行合约中，因此正确的第一条路由不再需要第二次模型传递。
- Kept self-contained follow-up prompts such as “再画一只狗，换个品种” independent from earlier prompts, preventing duplicate subjects in generated images.
- 路由提示从图像提取到视觉理解，以及多图像合成到参考图像生成。
- 将每个图像编辑仅限于一张目标图像和一个蒙版（如果存在）。
- `npm run check` 通过了 540 项测试。
