# ChatUI v1.9.6

This release repairs session backup export and import, including associated media.

- Export only sessions, messages, and images or attachments referenced by those sessions; model and API configuration is excluded.
- Restore complete session content instead of only the session list.
- Restore imported images and attachments and preserve their message references.
- Keep compatibility with older backup files, including backups without the newer format metadata.
- Fix media loss caused by normalizing an already-normalized backup during import.
