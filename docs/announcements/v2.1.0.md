# ChatUI v2.1.0 正式发布

ChatUI v2.1.0 已发布，本次更新重点如下：

## v2.1.0 更新内容

### 意图识别更快、更准

- 普通单任务只调用一次意图路由，请求响应更轻快；复杂请求才升级语义审查与定向修复。
- 单图片/单文件问答更稳定；输入不完整时在调用模型前就提示补充。
- 意图识别过程展示可折叠的决策轨迹，终态默认收起。

### 多实例在线人数

- 配置 `REDIS_URL` 后，多副本部署的在线人数全局一致，任一实例的变化都会实时同步。

### 使用提示

- 觉得理解有偏差，请在描述时清晰指定任务目标，也可以更换更高级的意图识别模型。
- 生图时如果给的内容有歧义、容易误导大模型，可以直接点击"强制生图"。

# 历史能力与使用建议（保留自 ChatUI 正式版发布）

ChatUI 现已进入**稳定运行期**，正式版面向日常使用发布。非阻塞问题将不再频繁发版，后续问题会集中记录，保持低频更新。

## 核心能力

### 聊天与内容处理

- 支持普通对话、长文本与流式输出，可展示思考过程、复制代码、编辑消息、重新生成并在会话内连续追问。
- 完整支持 Markdown、代码高亮、表格、数学公式（KaTeX）与 Mermaid 图表。
- 长任务支持后台运行、刷新后恢复、取消与失败提示。

### 智能意图路由

- 自动识别聊天、联网搜索、生图、看图、读文件与图片编辑等需求，无需手动切换模式。
- 图片任务支持多图规划与历史图片引用，例如"第八次生成""历史第 N 张"等定位。
- 支持会话级模型覆盖、全局/会话级 System Prompt，任务失败时给出明确原因而非模棱两可的提示。

### 图片生成与编辑

- 支持文生图、参考图生成、图片修改与多图合成。
- 支持一次并发生成或编辑多张图片（单次最多 5 张），例如"画一只加菲猫，分别生成五个视角的图片"。
- 生成结果支持预览、放大、键盘切换、跨消息连续查看、单图与批量下载；图片保存在本地，刷新后可恢复。

### 多模态与文件

- 支持图片、PDF、Word、PPT、Excel、文本/代码等附件，可进行图片理解、OCR、文件问答与多文件分析。
- 支持拖拽、粘贴与批量上传，并显示上传进度与处理状态。

### 联网搜索

- 可在对话中直接要求联网搜索最新信息，回答末尾提供去重后的来源链接。

### 会话与数据

- 支持多会话、会话搜索、消息目录快速跳转与历史记录恢复。
- 会话与图片默认仅保存在当前浏览器本地，服务器不会保存你的聊天内容或附件。
- 支持设置、导入、导出与备份，方便迁移本地数据。

### 使用体验

- 桌面端与移动端自适应布局，提供运行状态、任务进度、用量统计与问题反馈。

## 使用建议

- 为加载最新版本，请清除浏览器缓存后强制刷新：Windows 按 `Ctrl + F5`，macOS 按 `Cmd + Shift + R`。
- 如遇问题或建议，可通过右上角"反馈"提交；后续更新将保持低频、集中处理。
