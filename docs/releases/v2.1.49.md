# ChatUI v2.1.49

ChatUI v2.1.49 加入默认关闭的 HTTP / MCP 插件能力，并修复了在线人数徽标在浏览器“后退返回”后不再更新、可能被过期快照覆盖的问题。

## HTTP / MCP 插件（默认关闭）

- 新增服务端受控的插件旁路：管理员可在 `data/plugins.json`（可用 `CHATUI_PLUGINS_FILE` 覆盖）声明 HTTP 接口工具与远程 MCP 工具；该配置属于部署数据，不提交、不进入镜像。
- 输入区新增“插件”按钮，可查看并勾选允许自动调用的只读工具；需要逐次确认的写操作在面板中显示为禁用，服务端也会拒绝模型自动调用。
- 已选择工具时，聊天改用支持 function calling 的 Chat Completions 兼容模型，执行“模型工具调用 → 服务端插件请求 → 工具结果回传 → 最终回答”，最多 6 轮；未选择工具时完全沿用原有 Responses 流式链路。
- 安全边界：插件请求只由服务端发起，浏览器拿不到 baseUrl、Bearer 凭据或认证环境变量名；出站请求复用既有上游公网/HTTPS 校验与重定向限制；参数按受限 JSON Schema 校验，单次结果上限 512 KiB，默认超时 30 秒。
- 新增配置项 `CHATUI_PLUGINS_FILE` 与 `CHATUI_PLUGIN_TIMEOUT_MS`，示例见 `data/plugins.README.md`。

## 在线人数修复

- 修复浏览器“后退/前进”返回页面（bfcache 恢复）后不再重新订阅在线人数流的问题：此前该标签页会静默退出在线统计，徽标停留在离开前的数字，必须刷新页面才能恢复。现在 `pageshow` 与 `online` 会重建订阅并刷新人数。
- 修复首次加载的快照晚于实时推送到达时把徽标写回旧值、并一直卡住的问题：同一次会话内实时推送优先，过期的快照与已结束会话的回调都不再覆盖徽标。
