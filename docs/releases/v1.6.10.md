# ChatUI v1.6.10

## 新增

- Docker 部署可以升级到“1.6.10”或“v1.6.10”映像标签。
- 添加了一个回归，涵盖没有活动任务状态的持久对话的完成结算。
- 使用真正的 IndexedDB 支持的对话重现了失败，并验证了刷新后两条消息都呈现，没有控制台警告或错误。

## 修复

- 修复了重新打开包含已完成的用户和助理消息的对话时出现的启动警告。
- 防止没有活动任务记录的已完成持久对话在会话恢复期间取消引用丢失的任务状态。

## 删除

- 无。

## 其他

- 刷新后保持正常历史记录渲染、任务清理、编写器可用性和会话繁忙指示器同步。
- 更新浏览器捆绑包缓存版本，以便部署立即加载更正的任务生命周期代码。
- 通过 332 项测试验证了完整的项目检查套件。
