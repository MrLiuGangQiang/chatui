# ChatUI v1.10.3

这是 ChatUI 当前平台能力总览。它将对话、推理、图片、文档、会话、统计和部署能力集中在一个可直接运行的 OpenAI 兼容工作台中。本日志按用户可感知的平台模块完整记录能力边界，不是单次修复摘要。

## 产品定位与核心链路

- ChatUI 是单页前端加 Node.js 本地代理，可直接连接任意 OpenAI 兼容上游。
- 浏览器负责交互、会话状态、媒体预览和任务恢复；服务端负责代理、Job 生命周期、请求安全和上游转发。
- 每次发送都经过输入预检、附件捕获、意图识别/直接模式选择、结构化执行计划、请求转发和规范化结果提交。
- 聊天、图片和文件能力共享会话与媒体身份，避免同一份内容在不同功能链路中产生重复或失真的副本。

## 对话与模型

- 支持 OpenAI 兼容接口、自定义 Base URL、API Key 和额外 Header 参数。
- 支持聊天模型、路由模型、图片模型和模型列表自动加载；模型能力会参与输入校验与路由选择。
- 支持流式输出、停止生成、重新生成、编辑后重发、消息复制、下载和错误恢复。
- 支持自动意图路由，也支持直接模式；路由会在普通聊天、文件问答、图片生成和图片编辑之间选择合适链路。
- 支持 GPT 推理/思考模式、effort 类型、思考内容展示与按会话持久化。
- 支持系统提示词、会话提示词、图片风格提示词和模型级参数配置。
- 支持自定义模型选项、模型元数据、空模型回退和会话级模型覆盖；切换忙碌会话时会保护正在运行的任务。
- 支持中文和英文输入、IME 组合态 Enter 处理、粘贴清理、超长文本预检和移动端自适应输入框。

## 智能路由与任务契约

- 自动路由可识别普通问答、文件问答、文本生图、图片编辑、图片引用和多意图请求。
- 路由模型只接收必要的文本、附件元数据和图片引用元数据，不接收不必要的二进制内容。
- 结构化路由结果会经过严格 schema 校验，拒绝未知字段、越权资源、错误索引和不完整执行计划。
- 需要用户选择图片或补充编辑细节时，系统进入可恢复的澄清流程，支持多轮补充、选择、重放和重新生成。
- 路由失败、上游失败、取消和超时都会走统一错误与恢复边界，不会产生重复请求。

## 图片生成与编辑

- 支持文本生成图片、上传图片编辑、基于上一张图片继续修改和多图参考。
- 支持图片尺寸、风格、遮罩和参考图语义；图片结果支持预览、下载、复制和继续编辑。
- 图片附件使用多模态 `input_image`；JPEG、PNG、WebP 会尽量压缩，BMP 可转换为 PNG。
- 图片和生成结果通过 IndexedDB 持久化，刷新页面或切换会话后仍可恢复。
- 支持上一张生成图、历史图片、当前上传图和遮罩图的明确角色绑定，避免把不相关图片误用于编辑。
- 支持多图合成、参考图选择、图片候选缩略图、耐久化媒体 URL 和缺失媒体的安全降级。
- 支持图片生成任务的后台恢复、停止、重复提交保护、完成前结果保留和完成后规范化提交。
- 图片代理限制响应体大小，拒绝不安全重定向并只允许符合策略的上游地址。

## 附件与文件理解

- 支持点击附件按钮选择、将文件粘贴到输入区、一次选择多个文件；上传期间显示分阶段进度和发送禁用状态。
- 图片白名单：`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`、`.svg`，以及浏览器提供的 `image/*` MIME 类型。
- 图片处理：缩略图预览、稳定尺寸占位、JPEG/PNG/WebP 尽量压缩、BMP 转 PNG、作为聊天 `input_image`、作为图片编辑输入、IndexedDB 缓存和历史恢复。
- PDF：`.pdf`；使用原生 Responses `input_file.file_data`，支持 `auto`、`low`、`high` 页面图像清晰度。
- 表格：`.xla`、`.xlb`、`.xlc`、`.xlm`、`.xls`、`.xlsx`、`.xlt`、`.xlw`、`.csv`、`.tsv`、`.iif`、`.numbers`。
- 文档/富文档：`.doc`、`.docx`、`.dot`、`.odt`、`.rtf`、`.pages`。
- 演示文稿：`.pot`、`.ppa`、`.pps`、`.ppt`、`.pptx`、`.pwz`、`.wiz`、`.key`。
- 文本/代码：`.asm`、`.bat`、`.c`、`.cc`、`.conf`、`.cpp`、`.css`、`.cxx`、`.def`、`.dic`、`.eml`、`.h`、`.hh`、`.htm`、`.html`、`.ics`、`.ifb`、`.in`、`.js`、`.json`、`.ksh`、`.list`、`.log`、`.markdown`、`.md`、`.mht`、`.mhtml`、`.mime`、`.mjs`、`.nws`、`.pl`、`.py`、`.rst`、`.s`、`.sql`、`.srt`、`.text`、`.txt`、`.vcf`、`.vtt`、`.xml`、`.ts`、`.tsx`、`.jsx`、`.java`、`.go`、`.rs`、`.php`、`.rb`、`.sh`、`.bash`、`.zsh`、`.tex`、`.cs`、`.scala`、`.kt`、`.kts`、`.swift`、`.lua`、`.r`、`.jl`、`.ex`、`.exs`、`.erl`、`.hrl`、`.hs`、`.clj`、`.groovy`、`.dart`、`.awk`、`.hbs`、`.mustache`、`.ejs`、`.jinja`、`.jinja2`、`.liquid`、`.erb`、`.twig`、`.pug`、`.jade`、`.cmake`、`.gradle`、`.ini`、`.properties`、`.proto`、`.scss`、`.sass`、`.less`、`.hcl`、`.tf`、`.toml`、`.graphql`、`.gql`、`.ndjson`、`.json5`、`.yaml`、`.yml`、`.astro`、`.diff`、`.patch`、`.dockerfile`。
- 无扩展名的 `Dockerfile` 也按文本/代码文件识别；扩展名、MIME 和安全推断 MIME 会共同参与校验。
- 同时识别 PDF、Office、Google 文档/表格/演示、JSON、XML、YAML、CSV、Shell、Python、JavaScript/TypeScript、C/C++、Go、Rust、PHP、Ruby、Java、Kotlin、Swift、SQL、GraphQL、Markdown、SRT/VTT、日历、vCard、邮件等对应 MIME 类型。
- 非图片文件不会在浏览器或服务端本地提取正文，而是通过 Responses API 原生 `input_file.file_data` 发送；不会请求 `/v1/files`，不会与旧的内联文本重复发送。
- 原始文件 Blob 进入 IndexedDB；只有在实际请求或未完成任务恢复时编码为 Base64 Data URL，聊天历史只保存稳定附件描述和媒体引用。
- 支持附件预览、移除、PDF detail 选择、压缩说明、未解析状态、缺失 Blob 错误和跨会话附件隔离。
- 单个文件和同一请求中的文件合计都必须严格小于 10 MB；服务端还校验 Data URL、媒体类型、规范 Base64、解码字节数和请求体上限。
- 超限、空文件、类型不支持、Blob 丢失和请求合计超限均显示具体文件名及中文原因；失败卡片以红色 `alert` 保留，并提供右上角“×”关闭按钮。
- PDF 的扫描页、图片和图表需要上游模型具备视觉输入能力；非 PDF 嵌入图片和图表不保证进入视觉上下文，需要保留版式时应转换为 PDF。

## Markdown 与富文本

- 支持 Markdown、表格、任务列表、脚注、链接、Emoji、行内代码和代码块。
- 支持 KaTeX 数学公式、Mermaid 流程图和代码语法高亮。
- 流式输出期间提供稳定的增量 Markdown 预览，完成后使用同一套安全渲染与净化链路。
- 宽表格和代码块在内容区域内滚动，移动端不会造成页面横向溢出。
- 支持详情折叠、引用、列表、链接安全处理、图片耐久化引用和消息内操作按钮。
- 流式 Markdown 会保留未闭合代码块、表格和 details 的稳定预览，避免输出过程中闪烁或丢失已显示内容。
- 支持代码复制、Mermaid 重渲染/切换、图片放大预览、答案下载和消息级复制。

## 界面与交互

- 主界面包含会话侧栏、消息区、模型与模式控制、附件栏、输入框、发送/停止按钮和任务状态区。
- 欢迎页、空会话、错误消息、助手消息、用户消息、图片结果和附件消息具有独立的语义结构。
- 支持桌面宽屏、平板和 640px 以下移动端布局；弹窗、日志、表格、代码和输入区会按视口重新排布。
- 提示、确认、错误和恢复操作使用统一对话框/Toast 能力，并保持焦点、键盘操作和 `aria-live` 语义。
- 更新日志弹窗支持版本卡片、最新版本标记、按需加载历史、共享 Markdown 渲染和独立横向滚动。

## 会话与任务恢复

- 支持多会话、新建/切换/重命名/删除会话，以及会话级模型、思考和提示词设置。
- 聊天记录、会话元数据、附件 Blob、图片结果和未完成任务按职责保存在浏览器本地。
- 支持刷新后恢复未完成聊天或图片任务，避免网络抖动或页面离开导致任务丢失。
- 支持滚动跟随、手动阅读锁定、恢复按钮和长内容渐进渲染。
- 支持会话备份导出/导入；备份不包含 API Key 等本地敏感配置。
- 支持会话元数据压缩、重复消息去重、历史锚点、编辑替换、重新生成槽位和跨会话任务所有权校验。
- 支持配额不足时的增量快照回退、IndexedDB 超时保护、延迟写入重试和可恢复的未完成快照。
- 删除会话时会清理关联图片、附件 Blob、Job 标记、恢复标记和定时器，避免跨会话污染。

## 本地存储与备份

- 聊天记录、会话列表、活动会话、UI 偏好、推理偏好和任务快照使用版本化 localStorage/sessionStorage。
- 图片和非图片附件二进制使用 IndexedDB；聊天快照只保存稳定引用和必要元数据。
- 备份支持会话、消息、附件描述、图片描述和便携媒体；导入前校验版本、重复 ID、媒体引用和大小上限。
- 配置、API Key、额外 Header 和其他敏感字段不会被导出到备份，也不会进入模型上下文。

## 使用统计与安全

- 可选 PostgreSQL 使用统计、部门汇总、排行榜和导出能力；未配置数据库时核心功能不受影响。
- 服务端提供 OpenAI 兼容代理、任务 Job API、流式事件、图片代理和版本/配置接口。
- 代理限制请求体、校验 Base64 文件、过滤敏感日志、校验 URL 解析并阻止不安全的内部地址访问。
- 前端使用共享 Markdown 净化链路；配置、密钥和意图追踪信息不会写入聊天快照。
- 统计模块与聊天、生图、图片编辑、附件和路由解耦；数据库未配置时统计接口明确返回不可用状态而不影响核心功能。
- 安全日志只记录目标主机/路径、请求方法、字节数和安全错误码，不记录 API Key、Base64、文件正文或完整提示词。
- 服务端校验请求体、文件解码大小、HTTP 方法、CORS、重定向链、DNS 解析和私有地址访问策略。

## 服务端 API

- 提供公共配置与版本接口，返回可展示版本、构建身份、Git SHA 和运行模式。
- 提供聊天、流式聊天、Responses Job、图片 Job、任务事件订阅、任务停止和图片代理接口。
- 提供 OpenAI 兼容 `/v1/models`、聊天、Responses、图片生成和图片编辑转发能力。
- Job 接口保存最小化可恢复快照，支持排队、运行、完成、失败、取消、恢复和事件重放。
- 静态服务保留根入口、vendor 资源、内容寻址的浏览器 bundle 和 Docker runtime 所需的所有资产。

## 部署与工程

- 支持 Node.js 直接启动和 Docker 部署，提供 Docker Hub 与阿里云 ACR 镜像。
- 镜像使用不可变候选 digest 构建并验证运行时版本、Git SHA 和 source fingerprint 后再晋级标签。
- 静态入口、共享核心模块、浏览器工作流和服务端边界保持清晰，避免重复实现。
- 项目提供架构检查、语法检查、单元测试、服务端冒烟测试和 Docker runtime 验证。
- 支持 `npm start` 本地启动、Docker 构建、Docker Compose/容器编排和固定端口健康检查。
- 镜像发布同时覆盖 Docker Hub 与阿里云 ACR，并提供 `latest`、语义版本、`v` 前缀和不可变 SHA 标签。
- 发布流水线先构建候选镜像，再按 digest 启动并验证 `/api/version`、静态资源、Git SHA 和 source fingerprint，验证通过后才晋级标签。
- 代码按 shared、client/core、client/app、client/services、client/ui、server 和 test 分层，架构检查防止浏览器/服务端边界回退。

## 测试与质量门禁

- 单元测试覆盖附件格式与大小、原生文件输入、路由契约、澄清协议、会话存储、媒体持久化、任务生命周期和安全策略。
- 浏览器工作流测试覆盖输入法、流式 Markdown、滚动跟随、弹窗焦点、移动端布局、图片预览和更新日志。
- 服务端测试覆盖 API 契约、请求体限制、Base64 解码、代理安全、Job 恢复、错误脱敏和静态资源冒烟。
- 发布前执行项目检查、架构检查、语法检查、全量测试和 Exact Docker runtime；任一门禁失败都不会打标签。
