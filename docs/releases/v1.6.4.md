# ChatUI v1.6.4

## 新增

- Docker 部署可以升级到“1.6.4”或“v1.6.4”映像标签。
- 仅为拥有活动或持久工作的会话保留分离的会话 DOM，同时在会话再次变为活动状态时协调可变的进度详细信息。
- 当缓存的会话 DOM 被丢弃时，保留媒体对象 URL 所有权。

## 修复

- 将实时作业和可恢复作业重新绑定到其稳定的显示标识，以便进度更新在正确的消息位置继续进行。
- 添加了待提交恢复、托管作业重新绑定、路由切换、规范历史修复和稳定会话 DOM 缓存的回归。
- 当从会话切换回来时，保持待处理的聊天和图像任务可见，而不会创建重复的占位符消息。
- 将规范历史验证与待处理任务投影分开，防止合法的待处理消息触发不必要的历史修复。

## 删除

- 无。

## 其他

- 当接受提交时，包括在路由期间和第一个上游令牌到达之前，立即显示持久挂起任务。
- 通过 290 项测试验证了完整的项目检查套件。
