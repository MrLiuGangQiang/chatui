# ChatUI v1.8.17

This stability release restores the proven v1.8.7 application baseline and keeps only narrowly verified fixes.

- Remove the post-v1.8.7 Origin restriction, concurrent snapshot merging, oversized SSE event limit, and related runtime rewrites.
- Preserve v1.8.7 message replacement, session persistence, image-edit recovery, attachment extraction, and upstream safety behavior.
- Make the first mouse or pen session switch reliable while another session has a running task.
- Preserve split UTF-8 characters correctly while parsing proxied streams and safely reject malformed encoded job IDs.
- Keep Docker publishing bounded without exporting the workflow cache that previously stalled releases.
