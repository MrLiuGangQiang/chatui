# ChatUI v1.6.2

## 新增

- Docker 部署可以升级到“1.6.2”或“v1.6.2”映像标签。
- 使用规范助理消息保留已完成的推理内容，以便其在页面刷新后仍然存在。
- 添加了端到端持久性回归，涵盖请求启动、会话切换、完成、快照存储和完全重新加载。

## 修复

- 恢复保存的推理以及答案，即使对于未来的请求禁用推理也是如此。
- 防止切换到具有不同推理设置的会话清除另一个会话的活动推理输出。
- 当会话切换后响应稳定时，保持已完成的推理可见。

## 删除

- 无。

## 其他

- 保持正在进行的请求与其原始会话中选择的推理模式和工作量绑定。
- 对流、回退请求和 GPT-5 响应负载使用请求范围的推理设置。
- 通过 268 项测试验证了完整的项目检查套件。
