# ChatUI v1.10.3

这是 ChatUI 当前平台能力总览。它将对话、推理、图片、文档、会话和部署能力集中在一个可直接运行的 OpenAI 兼容工作台中。

## 对话与模型

- 支持 OpenAI 兼容接口、自定义 Base URL、API Key 和额外 Header 参数。
- 支持聊天模型、路由模型、图片模型和模型列表自动加载；模型能力会参与输入校验与路由选择。
- 支持流式输出、停止生成、重新生成、编辑后重发、消息复制、下载和错误恢复。
- 支持自动意图路由，也支持直接模式；路由会在普通聊天、文件问答、图片生成和图片编辑之间选择合适链路。
- 支持 GPT 推理/思考模式、effort 类型、思考内容展示与按会话持久化。

## 图片生成与编辑

- 支持文本生成图片、上传图片编辑、基于上一张图片继续修改和多图参考。
- 支持图片尺寸、风格、遮罩和参考图语义；图片结果支持预览、下载、复制和继续编辑。
- 图片附件使用多模态 `input_image`；JPEG、PNG、WebP 会尽量压缩，BMP 可转换为 PNG。
- 图片和生成结果通过 IndexedDB 持久化，刷新页面或切换会话后仍可恢复。

## 附件与文件理解

- 支持点击上传、粘贴上传和多文件同时上传。
- 支持图片、PDF、表格、Office 文档、演示文稿、文本和代码文件。
- 非图片附件通过 Responses API 原生 `input_file.file_data` 发送，不依赖浏览器或服务端本地解析。
- PDF 支持 `auto`、`low`、`high` 三档 `detail`；文件正文不会写入聊天历史。
- 单个文件及同一请求中的文件合计必须严格小于 10 MB，前后端执行一致校验。
- 超限或不支持的文件会显示红色、可读的错误卡片，错误不会静默消失，支持右上角“×”关闭。

## Markdown 与富文本

- 支持 Markdown、表格、任务列表、脚注、链接、Emoji、行内代码和代码块。
- 支持 KaTeX 数学公式、Mermaid 流程图和代码语法高亮。
- 流式输出期间提供稳定的增量 Markdown 预览，完成后使用同一套安全渲染与净化链路。
- 宽表格和代码块在内容区域内滚动，移动端不会造成页面横向溢出。

## 会话与任务恢复

- 支持多会话、新建/切换/重命名/删除会话，以及会话级模型、思考和提示词设置。
- 聊天记录、会话元数据、附件 Blob、图片结果和未完成任务按职责保存在浏览器本地。
- 支持刷新后恢复未完成聊天或图片任务，避免网络抖动或页面离开导致任务丢失。
- 支持滚动跟随、手动阅读锁定、恢复按钮和长内容渐进渲染。
- 支持会话备份导出/导入；备份不包含 API Key 等本地敏感配置。

## 使用统计与安全

- 可选 PostgreSQL 使用统计、部门汇总、排行榜和导出能力；未配置数据库时核心功能不受影响。
- 服务端提供 OpenAI 兼容代理、任务 Job API、流式事件、图片代理和版本/配置接口。
- 代理限制请求体、校验 Base64 文件、过滤敏感日志、校验 URL 解析并阻止不安全的内部地址访问。
- 前端使用共享 Markdown 净化链路；配置、密钥和意图追踪信息不会写入聊天快照。

## 部署与工程

- 支持 Node.js 直接启动和 Docker 部署，提供 Docker Hub 与阿里云 ACR 镜像。
- 镜像使用不可变候选 digest 构建并验证运行时版本、Git SHA 和 source fingerprint 后再晋级标签。
- 静态入口、共享核心模块、浏览器工作流和服务端边界保持清晰，避免重复实现。
- 项目提供架构检查、语法检查、单元测试、服务端冒烟测试和 Docker runtime 验证。

## 验证

- `npm run check`：项目、架构、语法检查和全部自动化测试通过。
