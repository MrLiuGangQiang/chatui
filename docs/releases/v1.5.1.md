# ChatUI v1.5.1

## 新增

- 添加了重点回归测试，用于验证提交工作流包装器无法移动路由标头和路由上下文。

## 修复

- 将修复应用于正常消息和引用消息路由路径。
- 升级后刷新浏览器以确保加载更新的提交工作流程。如果应用程序从 Docker 映像运行，请升级到“1.5.1”或“v1.5.1”映像标签。
- 修复了路由分派参数不匹配的问题，该问题可能导致路由模型返回后对话陷入意图识别阶段。

## 删除

- 删除了推送和拉取请求 CI 工作流程。 Docker 镜像构建和 GitHub 发布发布仅针对语义发布标签 (`vMAJOR.MINOR.PATCH`) 继续运行。

## 其他

- 后续请求（例如修改先前生成的 HTML 页面）现在会传递正确的请求标头和路由上下文，然后按预期继续配置的聊天模型。
- 更改了提交工作流浏览器缓存版本，以便刷新后的客户端立即收到更正后的工作流。
- 无需数据迁移或配置更改。
