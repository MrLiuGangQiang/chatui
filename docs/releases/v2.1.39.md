# ChatUI v2.1.39

## Changes

- 修复刷新或切换会话后，长回答只显示后半段的问题。现在刷新会先显示“正在恢复完整内容…”，随后继续输出或恢复完整回答，网页、代码等长内容不再从中间断开。
- 修复任务在后台继续输出时刷新页面无法接续的问题：即使本地任务记录丢失，界面仍会自动找回正在进行的任务并继续输出；任务已失效时会明确提示，不会再反复出现 404。
- 修复生成的长网页/代码刷新后看起来“只剩半截”的问题：恢复后的长代码块现在从开头显示，点击“查看完整内容”可展开全文；流式输出期间仍保持跟随最新一行。
- 修复固定模式下把网页、代码等文字请求误判成生图的问题：模式只用于判断当前能否执行，不会改变请求类型。
- 补充与本次修复对应的回归测试与设计文档。

## Verification

- `npm run check`：2138 tests / 359 files 全部通过。
- 流式输出专项：40 tests / 9 files 全部通过。
- 浏览器实测：长网页输出中途刷新后可恢复完整内容，已失效任务会转入明确错误状态且不再残留 404。
