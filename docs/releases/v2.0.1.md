# ChatUI v2.0.1

## Changes

- 意图识别升级为“理解 → 路由 → 校验/修复”思维链：多任务请求的拆分更稳定，编号选择支持中文数字，任务拆解不忠实时会自动修正。
- 修复任务选择回合的文件/图片绑定丢失问题，选中任务直接携带对应资源执行。
- 同一轮对多张图片提同一个问题（如“第二张和最后一张是什么颜色”）会合并为一次识图，不再拆成多个任务。
- 等待提示现在会显示当前所处阶段（读取上下文、理解请求、判断意图、拆分任务等）。
- 编辑后重发与重新生成现在也走意图识别，行为与新发送一致。
- 多任务计划在刷新页面后可恢复，继续选择未执行的任务。
- 会话提示词/模型按钮在启用时会保持可见的激活状态。
