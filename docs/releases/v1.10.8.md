# ChatUI v1.10.8

## Changes

- 强化 Markdown 与图片内容安全策略，拦截危险链接、协议和嵌入元素，同时保留常用图片格式与安全样式。
- 统一模型列表与路由配置：去除旧的直连模式，补充未知模型识别、类型推断、重复项处理和加载失败提示。
- 浏览器请求统一经过本地代理，图片下载不再向返回地址泄露 API Key；IndexedDB 不可用时会明确报告存储错误。
- 完善使用统计与反馈接口的 API Key/模型校验、缓存和错误提示，并整理配置备份卡片与移动端布局。
- 建立 `version.json` 唯一版本源；正式发版通过 `npm run release:prepare` 自动递增版本并同步 npm 镜像字段。
