# ChatUI v1.5.2

## 新增

- Docker 部署可以升级到“1.5.2”或“v1.5.2”映像标签。
- 即使对后续请求禁用推理，刷新后仍保留已完成的推理内容。
- 升级后刷新浏览器，以便加载更新的浏览器工作流资源。

## 修复

- 修复了切换对话或刷新页面时正在进行的托管聊天任务的恢复。
- 现在，当待处理的显示快照滞后或带有不同的作业 ID 时，持久聊天作业记录仍然具有权威性，从而保留重新连接或重新创建服务器端作业所需的请求负载。
- 现在，返回流仍在当前页面中运行的对话会重新绑定现有流，而不是打开重复的恢复连接。
- 添加了持久作业/显示协调、会话切换实时流重新绑定、挂起显示保留、推理历史持久性和配额失败恢复的回归覆盖。

## 删除

- 在陈旧显示清理之前，待处理的输出显示记录会与持久任务协调一致，因此在恢复期间不会删除可见的流媒体锚点。
- 本地存储配额失败不再删除之前的可恢复作业备份。

## 其他

- 无需迁移或配置更改。
