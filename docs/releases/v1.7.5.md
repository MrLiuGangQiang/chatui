# ChatUI v1.7.5

## 新增

- 用重新设计的“ChatUI 奥哲AI小助手”欢迎体验替换了空会话上的嵌入式意图路由图。
- 通过紧凑的高级布局、更密集的功能卡和两列移动网格减少了欢迎页面的占用空间。
- 验证了 Microsoft Edge 中桌面、短桌面和移动视口大小的重新设计的欢迎页面。
- 确认呈现的标题和功能标签具有预期的 Unicode 代码点，没有替换字符或重复的问号。

## 修复

- 将桌面欢迎内容放置在作曲家上方的可用空间内，同时保持短屏幕和移动布局安全地顶部对齐。
- 使用 ASCII 安全的 JavaScript Unicode 转义符对欢迎副本进行编码，以防止 PowerShell、静态捆绑、代理和不可变浏览器缓存中的中文文本损坏。
- 添加了智能意图路由、深度推理、多模式创建和连续会话恢复的简洁亮点，同时保留了现有的使用通知。
- 添加了欢迎内容、布局密度、响应式定位、缓存版本和编码安全性的回归覆盖范围。
