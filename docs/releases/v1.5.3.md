# ChatUI v1.5.3

## 新增

- Docker 部署可以升级到“1.5.3”或“v1.5.3”映像标签。
- 现在，仅当原始请求在上游接受之前和任何答案输出开始之前失败时，流回退才会创建替换请求。
- 添加了针对接受流重试抑制、旧版本地存储迁移、版本一快照升级和当前快照优先级的回归覆盖。
- 升级后刷新浏览器，以便加载更新的工作流和会话持久资源。

## 修复

- 修复了当接受的流请求稍后遇到 SSE、渲染或持久性错误时，一条消息可能会创建两个上游完成的问题。
- 恢复了 IndexedDB 会话快照迁移之前版本保存的对话的自动加载。
- 旧的每会话消息、已完成的显示记录、待处理任务和最后生成的图像状态均已标准化并迁移到当前快照 v2 格式。
- 现有快照 v2 数据仍然比过时的本地存储备份具有权威性，并且在迁移过程中保留旧备份以确保恢复安全。

## 删除

- 无。

## 其他

- 无需手动数据转换。旧版对话在首次加载时会自动迁移，前提是浏览器存储仍然存在于同一源下。
