# ChatUI v1.7.11

## 新增

- 添加了会话模型切换、显式路由模型切换、跟随模式、不同模型回退、无效合同、待澄清路由和繁忙任务模型防护的回归覆盖。

## 修复

- 恢复了稳定的 v1.7.8 意图路由回退行为，因此不会通过相同的重复请求重试不可用的模型。
- 确保待澄清分类使用目标会话的有效路由模型。
- 确保在下次提交时读取会话和显式意图识别模型更改，而不保留过时的模型选择。
- 防止任务运行时会话、全局聊天和意图识别模型发生更改，从而避免在一次提交中执行混合模型。
- 恢复了配置 UI 中被阻止的全局模型选择，并保持之前保留的模型不变。

## 删除

- 无。
