# ChatUI v1.8.18

This release fixes image-task recovery consistency and reduces the primary browser bundle.

- Prevent session re-entry from starting a second image-job follower and elapsed-time timer when the live run already owns the job.
- Keep recovered image results at the same canonical message position before and after a page refresh.
- Move the self-hosted KaTeX and highlight.js runtimes out of `chatui.bundle.js`, reducing its Brotli size by about 24.5% while preserving local Markdown dependency loading.
- Add regression coverage for image follower ownership, canonical result placement, and deferred bundle assets.
