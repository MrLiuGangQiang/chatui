# ChatUI v1.5.4

## 新增

- Docker 部署可以升级到“1.5.4”或“v1.5.4”映像标签。
- 为不相交的转换历史、仅前缀快照、规范重新索引、元数据保存和当前快照优先级添加了回归覆盖。

## 修复

- 部分快照现在可以恢复丢失的旧消息，同时保留升级后发送的消息并重新索引组合对话而不会发生冲突。
- 提高了会话持久性和静态捆绑缓存版本，以便浏览器在部署后立即加载恢复修复程序。
- 修复了存储转换回归，其中不完整的 IndexedDB v2 快照可能会隐藏仍保留在旧本地存储中的更完整的对话历史记录。
- 修复的历史记录将作为更新的持久 v2 快照写回，因此后续加载将使用恢复的规范记录。
- 如果受影响的对话需要恢复，请不要在升级前清除浏览器站点数据；保留的旧本地存储备份是恢复源。
- 升级后，刷新一次页面。受影响的历史记录会在会话加载时自动修复。

## 删除

- 无。

## 其他

- 完整的当前快照相对于较短的过时备份仍然具有权威性。
