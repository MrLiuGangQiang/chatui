# ChatUI v1.8.4

## Clarification image selection

- Kept structured image selections separate from execution instructions, preventing candidate ordinals, labels, and filenames from being misread as regions inside an image.
- Required the final route to preserve the exact image selected during clarification instead of silently binding a different candidate.
- Simplified clarification choices to numbered thumbnails without customer-facing filenames.
- Changed thumbnail choices to fill each row before wrapping responsively onto the next row.

## Engineering guidance

- Added a repository rule requiring verified root-cause fixes instead of symptom-masking patchwork changes.

## Verification

- Added regression coverage for neutralized execution prompts, stable selected-image binding, filename-free presentation, and row-first responsive layout.
