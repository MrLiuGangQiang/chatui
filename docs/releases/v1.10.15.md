# ChatUI v1.10.15

## Changes

- Improve route decision compilation and repair so clarification choices, resource bindings, constraints, and execution readiness remain stable across follow-up turns.
- Preserve source attachments and image context during continuation, regeneration, masking, and multi-image workflows.
- Improve session display and task lifecycle handling for route changes, image results, and continued submissions.
- Add opt-in, bounded request tracing with correlation IDs and redaction for credentials, binary payloads, data URLs, and signed query values.
- Expand regression coverage for clarification protocols, route invariants, attachment continuity, image positioning, session snapshots, and request-trace safety.
- Update architecture and development documentation for the revised browser/server boundaries and diagnostics.
