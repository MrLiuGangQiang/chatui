# ChatUI v2.1.5

ChatUI v2.1.5 修复重新生成/编辑重发时意图识别携带了被替换轮次之后上下文的问题，避免路由模型被未来消息误导。

## 修复

- 重新生成与编辑重发的意图识别上下文现在以被替换用户轮次为边界：只携带该轮之前的消息，以及由这些前缀消息重建的执行证据、候选和会话焦点。
- 被替换的旧助手回复、其后的所有对话内容、后续执行结果和缓存提示不再进入路由模型。
- 统一提交链路的 currentTurn 边界保持不变，普通新发送请求不受影响。

## 稳定性与质量

- 新增回归测试：替换链路意图上下文只包含被替换轮次之前的消息，旧回复与后续轮次均不可见。
- `npm run check` 全量通过（1796 个测试，313 个套件）。
