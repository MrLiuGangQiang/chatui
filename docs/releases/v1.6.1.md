# ChatUI v1.6.1

## 新增

- Docker 部署可以升级到“1.6.1”或“v1.6.1”映像标签。
- 将原始内存中运行保留为唯一执行所有者，直到其完成或停止。

## 修复

- 修复了会话切换重新启动正在进行的意图识别请求的问题。
- 防止重复切换为同一待处理消息创建重复的路由、聊天或图像请求。
- 刷新后序列化持久的待提交恢复，以便每个会话只能运行一次恢复尝试。
- 防止并发任务完成竞相覆盖相同的响应槽或会话快照。
- 防止重复会话切换时最新的用户消息丢失。
- 添加实时运行所有权、单次恢复、停止任务恢复和切换后节点重新绑定的回归覆盖。

## 删除

- 无。

## 其他

- 切换回来后，将意图识别和响应占位符重新绑定到当前渲染的会话节点。
- 继续显示路由阶段进度，而不是在任务再次可见之前等待答案输出。
- 通过 267 项测试验证了完整的项目检查套件。
