# ChatUI v2.1.1

ChatUI v2.1.1 修正了在线人数统计的语义：在线人数现在按"浏览器/设备"去重，同一浏览器打开多个标签页只计 1 人，更真实地反映同时在线的使用者数量。

## 在线人数按设备去重

- 在线人数不再按打开的标签页计数，而是按浏览器/设备去重：同一浏览器开多个标签页计 1 人，不同浏览器/设备各计 1 人。
- 身份来自浏览器自动携带的签名 principal cookie（HttpOnly、SameSite=Strict），无需用户操作；刷新页面、网络抖动重连不会重复计数。
- 关闭页面立即减 1（最后一个标签页关闭时）；页面异常退出（崩溃/断网）由心跳与 TTL 兜底，最长约 120–150 秒内自动清理。
- 多实例部署（`REDIS_URL`）时同样按设备去重，跨实例共享同一份在线数；多实例需配置相同的 `CHATUI_PRINCIPAL_SECRET` 才能正确去重（与任务归属要求一致）。
- 未配置 `REDIS_URL` 时保持单实例内存逻辑；未携带 principal cookie 的客户端回退按标签页计数，行为兼容。

## 稳定性与质量

- 新增同设备多标签页去重、设备切换、跨实例去重、心跳与清理等回归门禁；`npm run check` 全量通过。
