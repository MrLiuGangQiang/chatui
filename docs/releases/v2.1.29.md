# ChatUI v2.1.29

## Changes

- 移动端公告改为正文优先：隐藏推荐模型和重要说明等辅助区域，只保留标题、正文和阅读操作，并适配顶部、底部安全区。
- 移动端图片编辑器改为固定单屏布局：操作历史为空时自动收起，画布使用剩余高度；顶部和底部工具栏采用统一的紧凑图标布局。
- 移动端“撤销 / 重置 / 清空 / 提交 / 取消”保持单行排列，清空操作默认显示并在不可用时置灰。
- “调整尺寸”菜单改为底部面板，评论输入与操作区域适配窄屏，桌面端布局和交互保持不变。

## Verification

- `npm.cmd run check`：项目、架构、语法检查及 1998 个测试全部通过。
- 已使用本机 Headless Edge 完成 390px 级移动视口截图评审，覆盖公告正文、图片编辑画布、历史区与底部工具栏。
