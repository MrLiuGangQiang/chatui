# ChatUI v2.1.33

## Changes

- 修复多个会话同时流式输出时刷新页面后，部分会话停在等待状态、但服务端 Job 实际仍正常完成的问题。
- 浏览器现将所有 chat Job 合并到一条 SSE 多路连接，按 `jobId` 分发增量与断点 offset；单个 Job 完成不会关闭或污染其他会话的订阅。
- 保持会话隔离：每个恢复 follower 只更新自己的会话状态、DOM 和 canonical 消息，不抢占当前会话的输出焦点。

## Verification

- `npm run check`：项目、架构、语法检查及 2030 个测试全部通过。
- 新增客户端和服务端 Job SSE 多路复用回归测试，覆盖多 waiter 共用一个 EventSource、事件按 `id` 分发，以及单 Job 终态隔离。
- 真实 Edge 验证：8 个会话同时输出时刷新页面，8 个会话均继续接收 SSE 增量并独立完成提交。
