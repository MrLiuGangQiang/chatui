# ChatUI v1.7.1

## 新增

- 无。

## 修复

- 在生成的图像持久性和历史恢复过程中保留图像描述、提示、标签和修订的提示。
- 跨多个历史图像结果恢复所选图像，而不会默默地回退到单个图像。

## 删除

- 无。

## 其他

- 通过持久的语义元数据解析命名的历史图像，因此即使存在许多其他候选图像，诸如组合猫和狗之类的请求也会选择这些图像。
- 仅当所请求的图像无法唯一映射时才要求澄清，包括真正重复或未指定的主题。
- 使用重复的“image[]”多部分字段发送多图像编辑请求，以便每个选定的图像到达上游图像编辑 API。
- 完整的项目检查和 356 项自动化测试。
- 从对话历史记录到真实的 HTTP 多部分请求到模拟“/v1/images/edits”上游的端到端语义选择烟雾测试。
- 使用构建的静态包进行无头 Microsoft Edge (Chromium) 浏览器验证：加载了四个候选图像，仅选择了猫和狗，并且没有发生页面错误。
