# ChatUI v1.7.8

## 新增

- 将欢迎页面中心卡替换为专用的动画地球仪，以获得更清晰、更集中的首次运行体验。
- 添加了分层大气、海洋、网格、陆地、闪烁、光环、倾斜和漂浮效果，使地球更具深度。
- 调整地球仪尺寸以实现紧凑的桌面布局，同时保留周围的功能轨道。
- 添加了针对全球标记、响应式样式、动画挂钩、简化运动行为和缓存版本的回归覆盖。

## 修复

- 无。

## 删除

- 从欢迎插图的中心删除了多余的“AI”和“READY”标签。

## 其他

- 当操作系统请求减少运动时禁用新的地球动画。
- 发布于 2026 年 7 月 20 日。
- 刷新了应用程序、主题和静态捆绑包缓存版本，以便浏览器立即收到更新的欢迎资产。
- `npm run check` 通过。
