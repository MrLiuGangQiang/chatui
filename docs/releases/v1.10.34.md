# ChatUI v1.10.34 — 联网搜索与多图体验升级

## Changes

- 新增联网搜索能力：可自动识别实时、最新信息需求，并在回答末尾展示去重后的来源链接；当前模型不支持时会给出明确提示。
- 优化纯图片输入与图片标签：没有文字时不再自动拼接附件名称，标签优先使用图片语义或有意义的文件名。
- 缩小图片澄清候选图，改进自适应横向排列、选择状态与刷新后的行为一致性。
- 提升多图生成、编辑和批任务的稳定性，修复候选重复、图片无法显示、终态重复处理及刷新恢复异常。
- 修复会话异步写入、历史图片路由和执行资源绑定问题，减少错误澄清与跨会话内容串联。
- 更新本地 Markdown 安全渲染依赖及静态资源版本，保持浏览器资源与 npm 锁定版本一致。
