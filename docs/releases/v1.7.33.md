# ChatUI v1.7.33

## Fixes

- Top-level JavaScript and CSS bundle URLs now use revisions derived automatically from their bundled source content, eliminating manual cache-version synchronization.
- The rendered homepage now guarantees that each bundle URL revision matches the bundle ETag, preventing stale routing logic or missing execution-map styles after deployment.
- Bundle metadata and manifest caches now use content hashes, so source changes are detected even when file sizes or timestamps are unchanged.

## Verification

- Ran `npm run check`: project, architecture, syntax, and all 477 automated tests passed.
- Added unit and server smoke coverage for content-addressed bundle revisions and homepage-to-bundle consistency.
