# ChatUI v1.9.0

This release adds portable browser data backup and restore.

- Export chat sessions, model and endpoint configuration, and persisted attachments or generated images to one JSON backup file.
- Restore a backup into the browser with validation for supported formats, duplicate sessions, and missing media.
- Exclude API keys, custom Header values, and session Header values by default; include them only through an explicit opt-in checkbox.
- Keep older unmarked backups and earlier portable backup versions importable.
- Register the backup workflow through the application workflow registry instead of adding another browser global.

Importing a backup replaces the current browser's chat records and configuration. Create a current backup first if the existing data may still be needed.
