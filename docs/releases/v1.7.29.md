# ChatUI v1.7.29

## Route contract reliability

- Valid first-pass route contracts now execute immediately and are no longer blocked by an independent AI review request.
- Route requests now prefer strict JSON Schema output for the complete `task_contract.v3` response.
- If a model expresses a valid intent but returns a contract that fails local validation, ChatUI sends one bounded repair request to the same model to correct the contract without changing the routing decision.
- Kept a compatibility fallback for OpenAI-compatible gateways that explicitly do not support structured outputs.

## Verification

- Ran `npm run check`: project, architecture, syntax, and all 465 automated tests passed.
