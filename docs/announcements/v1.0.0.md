# 全新公告中心上线

为了确保每一位使用者都能及时看到重要信息，ChatUI 现已上线全新的版本化公告中心。

## 你需要知道

- 最新公告在未阅读前会持续显示，并暂时锁定其他功能。
- 点击“我已阅读，进入 ChatUI”后，本公告不会再次自动弹出。
- 发布更高版本的新公告时，阅读状态会自动重置并重新提醒。
- 所有历史公告都会持续保留，可通过“查看历史公告”随时回顾。

感谢你的理解与支持。我们会仅将强制公告用于确有必要的重要信息。
