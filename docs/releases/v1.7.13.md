# ChatUI v1.7.13

## 修复

- 刷新浏览器和静态捆绑缓存版本，以便部署的客户端立即收到生命周期修复。
- 修复了完成聊天、图像生成和图像编辑任务导致作曲家陷入运行/停止状态的根本原因。
- 立即释放已完成的运行所有者并刷新 Composer 控件，恢复“发送”，而无需等待外部提交工作流程或异常/最终路径。
- 防止终端任务因延迟恢复事件而复活。
- 添加了接口拥有的完成排序、完成身份验证、幂等重复完成、过时任务隔离、终端恢复保护和立即作曲家投影的回归覆盖。
