# ChatUI v1.7.2

## 新增

- 记录内存中意图跟踪中实际使用的模型，以使路由配置可验证，而无需保留敏感请求数据。

## 修复

- 修复了意图识别模型的“跟随聊天模型”设置，以便保留清除旧的显式路由模型，而不是静默恢复它。

## 删除

- 无。

## 其他

- 将多图合成视为资源选择+图片上传，将用户的合成请求原样发送至图片API。
- 按语义定位指定的历史图像，通过重复的“image[]”字段仅上传选定的图像，并且仅在身份确实不明确时才要求澄清。
- 使意图识别遵循为目标会话选择的聊天模型，包括后台会话、会话切换、路由审查和显式路由回退。
- 完整的项目检查和 361 项自动化测试。
- 端到端图像冒烟测试可验证语义资源选择、准确的提示直通、重复的“image[]”多部分字段以及排除不相关的图像。
- 路由负载测试验证两个会话使用自己选择的聊天模型，显式路由模型仍然优先，回退使用会话模型而不是全局默认模型。
- 针对内置静态包的无头 Microsoft Edge 验证涵盖了精确的图像提示直通和会话感知意图模型有效负载选择，没有页面错误。
