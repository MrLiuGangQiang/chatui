# ChatUI 核心功能与近期更新

ChatUI 是一个面向日常使用的轻量级聊天与图片工作台，核心能力如下。

## 1. 聊天与内容处理

- 支持普通对话、长文本、Markdown、代码、表格、数学公式和 Mermaid 图表。
- 支持思考过程展示、代码复制、消息编辑、重新生成和会话内连续追问。
- 根据任务自动识别聊天、看图、读文件、联网搜索、生图和图片编辑等需求。

## 2. 图片生成与编辑

- 支持文生图、基于参考图生成、图片修改和多图合成。
- 现在支持一次生成或编辑多张图片，单次最多 **5 张**，采用并发执行，通常比逐张生成更快。
- 例如：`画一只加菲猫，分别生成五个视角的图片`。
- 支持下载、复制、分享和批量下载生成结果。

## 3. 图片预览

- 支持放大、缩小和双击还原。
- 支持上一张、下一张，以及使用 `←` / `→` 键盘方向键切换。
- 可以跨消息连续查看图片，并显示当前图片位置。

## 4. 文件与多模态能力

- 支持图片、PDF、文本、代码、表格等常见附件。
- 可进行图片理解、OCR、文件问答和多文件分析。
- 支持拖拽、粘贴和批量添加附件，并保留上传进度与处理状态。

## 5. 联网搜索

- 可在对话中要求 ChatUI 搜索最新信息，并在回答中查看来源。
- 例如：`联网搜索今天的人工智能新闻并给出来源`。

## 6. 会话与数据管理

- 支持多会话、会话搜索、消息目录快速跳转和历史记录恢复。
- 会话与图片默认保存在当前浏览器本地，服务器不会保存你的聊天内容或附件。
- 支持设置、导入、导出和备份，方便迁移本地数据。

## 7. 使用体验

- 支持桌面端和移动端布局，适配不同屏幕尺寸。
- 提供运行状态、任务进度、用量统计和问题反馈功能。
- 长任务支持后台恢复、取消和失败提示，便于持续处理图片与文件任务。

如需反馈问题或提出建议，可以使用右上角的“反馈”功能。
