# ChatUI v1.7.0

## 新增

- Docker 部署可以升级到“1.7.0”或“v1.7.0”映像标签。
- 用一个严格的“task_contract.v3”协议替换以前的模型路由形状，并且没有旧的适配器路径。
- 添加确定性结构化补丁以进行后续、校正、图像编辑和参考图像生成。
- 添加了严格路由契约、上下文隔离、结构化补丁组合、预插入大小检查和大输入布局行为的回归覆盖。

## 修复

- 防止不相关的新请求继承历史图像提示或资源。
- 在浏览器改变编辑器之前防止过大的粘贴、放置和文本插入。
- 使用单个“操作”字段来派生运行时 API 和模式，防止意图和执行字段相互矛盾。
- 跳过大型提示的同步“scrollHeight”测量，避免先前在发送之前发生的强制布局冻结。

## 删除

- 删除重复的文本区域调整大小侦听器，并保留最终提交防护以恢复或编程输入。

## 其他

- 即使修订后的置信度分数低于第一次通过，也会应用有效的 AI 审核更正。
- 将单条短信的长度限制为 120,000 个字符，并建议文件上传或分段消息以获取更大的内容。
- 通过 341 项测试验证了完整的项目检查套件。
