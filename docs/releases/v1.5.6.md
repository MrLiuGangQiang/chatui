# ChatUI v1.5.6

## 新增

- Docker 部署可以升级到“1.5.6”或“v1.5.6”映像标签。
- 添加了回归覆盖，以便在图像生成后立即进行会话切换。

## 修复

- 修复了切换对话后已完成的生成图像短暂返回“生成/加载”状态的问题。
- 当需要读取数据库时，同时恢复多个持久媒体元素。
- 添加了回归覆盖，确保可见的完整 Blob 图像不会返回到加载状态。

## 删除

- 当存储的图像被删除或图像数据库被清除时，释放缓存的对象 URL。

## 其他

- 重用已经可用的浏览器对象 URL，而不是隐藏图像并从 IndexedDB 重新读取它。
- 将静态捆绑包缓存版本提升到“1.3.106-image-session-switch”。
- 将媒体工作流模块缓存版本提升至“1.2.68-image-session-switch”。
