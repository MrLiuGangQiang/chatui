# ChatUI v2.1.53

本次发布补齐 MCP 按名称查询的能力，用户名和部门名均可直接查询。

## MCP 按名称查询

- 新增 `usage_get_user_by_name` 工具，调用参数为必填 `username` 和可选 `range`。
- 新增 `usage_get_department_by_name` 工具，调用参数为必填 `department_name` 和可选 `range`，同时返回部门聚合指标和部门用户用量。
- 用户名和部门名都按完整名称进行大小写不敏感精确匹配；同名 API Key 合并统计，同名部门分别返回；未找到时返回 `found:false`。
- 只返回与排行榜同级的聚合 token 指标，不开放请求日志或原始明细。
- 继续使用当前用户 API Key 鉴权，部门工具仍不需要部门密码。
- 更新 MCP 工具说明、README、架构与 API 契约文档。
