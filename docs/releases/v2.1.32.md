# ChatUI v2.1.32

## Changes

- 修复多个会话同时运行任务时可能跨会话串线的问题：后台任务只写入自己的会话数据，不能修改、抢占或删除当前会话的 DOM 节点和流式输出锚点。
- 修复正在通过 SSE 输出时切换会话或刷新页面后页面暂时不显示内容的问题；恢复时会立即重放所属会话已经累计的正文和思考内容，再继续等待后续增量。
- 后台任务完成时不再抢当前会话输入框焦点。
- 图片任务完成恢复、聊天 reasoning 恢复、pending 显示项清理和活跃输出注册均增加会话归属校验。
- 补充多会话并发、切换回来恢复、刷新恢复、后台图片完成和 DOM 所有权回归测试。

## Verification

- `npm run check`：项目、架构、语法检查及 2025 个测试全部通过。
- 已验证切换会话后立即重放累计正文与思考。
- 已验证刷新恢复时在下一段 SSE 到达前恢复可见输出。
- 已验证后台聊天、图片任务不会修改当前会话 DOM 或抢输入焦点。
