# ChatUI v2.1.52

本次发布新增面向外部 MCP 客户端的用量统计与问题反馈接口。

## MCP 用量统计与问题反馈

- 新增无状态 `POST /api/mcp` Streamable HTTP MCP JSON-RPC 2.0 服务，支持 `2025-06-18`、`2025-03-26`、`2024-11-05` 协议版本。
- MCP 访问令牌直接使用用户 API Key，仅接受 `Authorization: Bearer <API Key>` 或 `X-API-Key`；不接受 query string、JSON-RPC body 或工具参数中的共享凭据。
- 提供 8 个工具：用量概览、个人用量、用户排行、部门统计概览、部门排行、部门用户、部门 XLSX 导出和问题反馈。
- 部门统计工具直接使用当前用户 API Key 授权，不要求部门密码；浏览器现有部门密码机制保持不变。
- 问题反馈与浏览器入口共用审核、用户名解析和 DingTalk 投递链路；审核通过前不会解析用户名或发送外部消息。
- MCP 响应统一 `no-store`，支持无 Cookie 跨域调用；请求体限制 1 MiB，导出限制 8 MiB，并沿用统计与反馈限流。
- 新增 `validateKey` 无模型密钥校验及独立缓存隔离，避免 MCP 认证污染浏览器模型校验缓存。
- MCP 访问日志对 query string 强制脱敏，错误日志不记录 API Key、反馈正文或导出内容。
