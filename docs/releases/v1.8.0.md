# ChatUI v1.8.0

## Intelligent intent routing

- Reworked image, reference-image, edit-image, vision, file, and chat routing around one validated `task_contract.v5` protocol.
- Automatic routing now selects the operation, resources, API, and execution parameters without exposing internal product modes to users.
- Prevented inferred modes and resources from leaking between sessions or contaminating new requests.

## Reliable image execution

- Added canonical execution-resource projection and dispatch gates for targets, masks, references, quoted messages, and historical resources.
- Reference-image generation now correctly produces a new image while using the multipart image-edit transport internally.
- Hardened clarification rerouting, contract repair, multi-image composition, and image-mask persistence.

## Verification

- Added regression coverage for automatic mode isolation, route/resource consistency, clarification safety, repair invariants, reference-image generation, and mask execution.
- `npm run check` passes with 518 tests.
