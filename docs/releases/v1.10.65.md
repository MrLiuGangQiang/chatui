# ChatUI v1.10.65

## Changes

- Fix conversation persistence ordering so multi-turn chats continue to display as alternating question-and-answer pairs instead of grouping all questions before all answers.
- Make each conversation turn durable with stable message and turn identities; assistant replies are explicitly linked to the user message they answer.
- Editing a message now replaces only its matching reply and preserves all earlier and later conversation history.
- Keep chat, image, multi-image batch, refresh recovery, and local snapshot fallback records aligned when a session is saved or restored.
- Improve compatibility with structured-output gateways that reject advanced schema or reasoning options, with safe canonical retries.
