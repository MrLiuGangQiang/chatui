# ChatUI v2.1.40

## Changes

- 新增皮肤系统：提供默认、古韵、雪山三套皮肤，可在页面右下角切换；选择即时生效、刷新持久化，并在首屏渲染前应用以避免闪烁。
- 优化默认皮肤画布与当前会话选中样式：新增丝绢波浪背景，当前会话选择态更醒目。
- 强化图片任务连续性：刷新、后台任务恢复、单图与批量恢复会回灌路由与任务状态，旧记录中嵌套的“基础要求/修订要求”会被展开，避免下一轮修订继续嵌套旧文本。
- 强化图片编辑器直发与强制生图链路：确保任务状态随执行结果透传，后续追问和修订能正确定位。
- 修复超大历史消息导致刷新后可见记录过少的问题：历史尾部恢复始终至少保留 12 条消息。
- 补充皮肤完整性、任务恢复、批量恢复、编辑器续接与历史恢复的回归测试和设计文档。
