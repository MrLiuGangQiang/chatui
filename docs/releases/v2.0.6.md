# ChatUI v2.0.6

## 变更

- 修复（热修）：v2.0.5 移除 reasoning-workflow 的 `with(deps)` 时，把仅在测试调用中传入的 `isSessionBusy` 误写为 `deps.isSessionBusy`；生产入口的 deps 不含该项，导致启动时 `isReasoningControlLocked` 抛 `deps.isSessionBusy is not a function`（bootstrap failed）。现改为 `(deps.isSessionBusy ?? isSessionBusy)`：deps 提供时用 deps（测试），否则回落到入口 bundle 声明的全局 `isSessionBusy`（生产）。并新增回归测试，复现并锁定该生产故障。
