# ChatUI v1.7.27

## Intent routing and attachment continuity

- Fixed valid image-generation contracts that declare the current user text as a source resource being rejected locally and falling back to a second, inconsistent routing pass.
- Historical uploaded images, generated images, current attachments, and quoted attachments are now restored and forwarded according to the route contract's selected resources.
- A task that explicitly selects a required image now stops with a clear error if that image cannot be recovered or attached; it no longer continues without the intended visual reference.
- Reference-image generation sends only images selected as visual references, preventing unrelated attachments from entering the image request.
- Historical and current file candidates can now be considered together during routing.

- Ran `npm run check`: project, architecture, syntax, and all 446 automated tests passed.
