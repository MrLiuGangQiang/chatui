# ChatUI v1.10.74

## Changes

- Added continuous image preview across the conversation. Use the previous/next controls or Left/Right Arrow keys to browse images, with image position, download, copy, and zoom state kept in sync.
- Added support for multi-image generation and multi-image editing requests. A single request can produce or edit up to five images concurrently for faster completion.
- Refined the message quick-jump directory for more readable navigation in longer conversations.
