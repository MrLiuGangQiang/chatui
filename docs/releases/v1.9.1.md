# ChatUI v1.9.1

## 新增

- 添加了精确的运行时源指纹，涵盖复制到 Docker 映像中的每个应用程序文件。
- 添加了版本、Git 提交、源指纹、脏工作空间状态和运行时模式到“/api/version”；可见版本现在可以区分脏的本地工作区。
- 在升级版本标签之前，主 CI 和标签触发的发布工作流程需要精确的 Docker 运行时验证。

## 修复

- 保持澄清解释模型驱动，具有严格的部分答案验证和一种有界模型契约修复，而不是本地关键字或序数路由。
- 修复了当实时 DOM 节点保留陈旧的挂起任务所有权时，已完成的流式助理消息从页面消失直至刷新的问题。
- 当实际运行时文件与 CI 提供的源指纹不同时，使已识别的容器拒绝启动。
- 为 OCI 修订标签、API 身份、内容寻址捆绑包和关键浏览器修复添加了 clean-worktree 版本预览和精确图像运行时验证。

## 删除

- 无。

## 其他

- 将流式消息节点反弹到其当前显示投影，并在完成时同步清除挂起的所有权。
- Improved model-based clarification continuation so replies such as `2`, `第二张`, or `右边那只猫` can select one image while the assistant continues asking for a still-missing edit detail.
- 将 Docker 发布更改为构建不可变的候选者一次，验证候选者摘要，并在 Docker Hub 和阿里云 ACR 中将相同的摘要提升为“1.9.1”、“v1.9.1”和“最新”，而无需重建。
- 需要带注释的发行标签属于“main”，发行说明在发布之前出现在标记的提交中。
- 完整的项目、架构、语法、单元、回归和服务器烟雾检查。
