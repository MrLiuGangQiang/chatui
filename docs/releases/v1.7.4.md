# ChatUI v1.7.4

## 新增

- 添加了活动 IME 合成、旧 IME 键码 229、合成结束后立即发生的 Safari 样式 Enter 事件以及正常 Enter 提交的回归覆盖。
- 验证了 toast 与扩展桌面、折叠桌面和移动布局中的聊天/编写中心的对齐情况。
- 验证了 Microsoft Edge 中的 IME 事件序列，并确认提供的静态包包含更新的防护。

## 修复

- 停止恢复过时的存储模型（例如“gpt-image-2”）中的空可见图像模型选择。
- 添加了回归覆盖范围，确保空的可见聊天和图像模型选择覆盖过时的存储值。

## 删除

- 无。

## 其他

- 发布于 2026 年 7 月 20 日。
- 当使用 Enter 确认 IME 候选时，阻止 macOS 输入法发送消息；正常的 Enter-to-send 和 Shift+Enter 换行符保持不变。
- Centered transient toast messages, including “已清除所有会话”, over the active chat content region instead of the full browser viewport.
- `npm run check` 通过了 368 项测试。
