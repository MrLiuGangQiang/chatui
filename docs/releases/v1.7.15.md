# ChatUI v1.7.15

## 新增

- 保留模型声明的多图像路由覆盖范围并验证端到端多部分图像请求。

## 修复

- 无。

## 删除

- 从两个提交入口路径中删除了残留的无操作挂起任务本地回退；失败或无效的继续决策现在始终是一项新任务。
- 删除了本地图像合成关键字后备，该后备可能会使用不相关的图像说明覆盖有效的“task_contract.v3”响应。

## 其他

- 发布于 2026 年 7 月 22 日。
- 路由现在仅执行经过严格验证的模型合约；图像选择、模糊性和澄清仍然是合同的一部分，而不是从本地关键词或候选人评分中推断出来。
- 更改了路由器、提交工作流程和根条目资产版本，以便浏览器在部署后获取正确的逻辑。
- Added regression coverage for a standalone business request containing “多对多” and “自动合并行展示/分组” while prior image candidates exist.
