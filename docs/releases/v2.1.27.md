# ChatUI v2.1.27

## Changes

- 修复输出完整网页时聊天界面卡死的问题：网页源码改为安全代码块展示，页面 DOM、样式和脚本只在预览沙箱中运行。
- 大型代码块不再执行全量语法高亮，避免生成大量高亮节点；447 KB 网页实测从约 2.5 秒、11.2 万节点降至约 62 毫秒、2 个节点。
- 修复全屏图片预览中的“编辑”按钮偶尔无法点击、刷新页面后恢复的问题；预览每次显示时会清除上一次中断留下的禁用状态。
- 其他会话正在执行任务不会影响图片预览编辑；只有图片所属会话自身忙碌时，提交阶段才会提示等待。

## Verification

- `npm.cmd run check`：项目、架构、语法检查及 1994 个测试全部通过。
- 已使用本机 Headless Edge 复测大型网页输出，确认聊天主 DOM 不再包含页面内部节点、样式或脚本。
