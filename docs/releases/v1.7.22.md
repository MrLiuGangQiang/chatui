# ChatUI v1.7.22

## 新增

- 添加了细节流、规范最终渲染、大型 Markdown 和代码/美人鱼动作控件的回归覆盖。

## 修复

- 代码复制和美人鱼源/渲染控件现在可以在使用可见背景和微妙的圆角交互的同时保持稳定的几何形状。

## 删除

- 无。

## 其他

- 发布于 2026 年 7 月 23 日。
- 流式 Markdown 现在可以保持本机和速记细节块的原子性，同时向用户隐藏不完整的 Markdown 控制标记。
- 完整的流式 Markdown 通过一种规范解析进行协调，因此表格、列表和多行块与页面刷新后显示的结果相匹配。
- 大型 Markdown 响应被解析为一个完整的文档，批量安装在屏幕外，并自动交换到视图中。
- `npm run check` 在发布前通过。
