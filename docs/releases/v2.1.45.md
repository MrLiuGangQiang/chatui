# ChatUI v2.1.45

## Changes

- 修复问题反馈和使用统计会压暗、模糊并遮挡主页的问题。打开后只显示对应卡片，页面其余区域保持可见且可继续操作。
- 默认、古韵、雪山和宁静皮肤统一使用透明非模态浮层，不再保留任何全页遮罩或全局模糊。
- 反馈窗口同步改为非模态语义，关闭操作统一使用卡片内的关闭或取消按钮。
- 新增跨皮肤非模态回归门禁，防止后续修改重新引入全页遮罩、指针拦截或背景模糊。
