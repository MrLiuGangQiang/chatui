# ChatUI v1.8.2

## Smarter image routing

- Compiled compact semantic route decisions into validated execution contracts so a correct first route no longer needs a second model pass.
- Kept self-contained follow-up prompts such as “再画一只狗，换个品种” independent from earlier prompts, preventing duplicate subjects in generated images.
- Preserved explicitly quoted descriptions and genuinely incomplete follow-ups when they need prior text.
- Routed prompt extraction from an image to visual understanding, and multi-image composition to reference-image generation.

## Safer image editing

- Limited each image edit to exactly one target image and, when present, one mask.
- Added clarification for ambiguous edit targets and missing edit details without silently choosing an image or invoking fallback routing.
- Replaced unreadable image-choice text with compact numbered thumbnail candidates and removed unsupported “all images” choices.

## Verification

- Expanded routing, contract, clarification, context-boundary, and presentation regression coverage.
- `npm run check` passes with 540 tests.
