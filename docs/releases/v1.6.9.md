# ChatUI v1.6.9

## 新增

- 生成图像时保留完整的显式引用的消息描述，即使意图路由将请求分类为新任务。
- Docker 部署可以升级到“1.6.9”或“v1.6.9”映像标签。
- 添加的路由和提示合成覆盖范围证明了明确引用的描述可以在最终图像执行提示中保留下来，而不会继承不相关的历史记录。

## 修复

- 修复了在对话之间切换后已完成的背景图像作业仍停留在进行中状态的问题。
- 在清除临时恢复所有者之前，通过规范任务生命周期解决恢复的聊天和图像作业，保持编写器、停止/发送按钮和会话侧边栏同步。
- 正确完成已恢复的终端故障，同时保留瞬时传输中断的可恢复状态。
- 防止诸如“从引用的消息生成图像”之类的简短后续指令替换详细的引用场景、风格和构图要求。
- 为已完成的背景图像恢复、规范的繁忙状态发布、追随者清理和已完成的恢复快照添加了生命周期回归。

## 删除

- 无。

## 其他

- 验证了真实浏览器中的多对话背景图像完成流程：完成的图像保持可见，启用提示，发送按钮返回到“发送”，会话侧边栏不再显示活动答案。
- 通过 331 项测试验证了完整的项目检查套件。
