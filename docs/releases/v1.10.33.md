# ChatUI v1.10.33 — 多图路由与批任务稳定性

## Changes

- 优化纯图片输入：没有文字时默认把本轮上传图片作为整体分析对象，不再把文件名当作用户提示；目标确实不明确时再请求澄清。
- 上传图片标签改为“图片自身语义 → 有意义的文件名 → 第 N 张上传图片”，避免把整轮用户提示复制成每张图片的共同标签。
- 图片澄清候选改为更小的固定缩略图，并隐藏可见文件名，同时保留选择与预览能力。
- 修复多图逐张重生成和多图编辑的执行编译，确保每个子任务保留自己的目标图片、参考图片和执行资源。
- 修复多图批任务完成事件并发导致同一图片被重复转换、持久化或渲染的问题。
- 修复多图终态失败后恢复索引反复残留的问题，并统一错误展示边界，避免同一失败重复提示。
- 修复会话消息异步写入导致不同会话内容串联的问题。
- 升级 Undici、DOMPurify 与 Mermaid 安全修复版本，同步浏览器本地 vendor、CDN 回退和静态入口缓存版本。
