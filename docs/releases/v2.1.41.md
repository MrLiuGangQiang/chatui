# ChatUI v2.1.41

## Changes

- 修复雪山皮肤下公告中心、反馈弹窗与用量统计配色不统一的问题：这些面板原先保留默认的靛蓝/饱和蓝与紫、琥珀、玫红分档色，现在全部改用雪山的霜白玻璃与冰川蓝令牌，统计分档收敛为同一冷色渐变，名次奖牌降低饱和但保留语义。
- 修复统计徽章分档色被通用兜底规则覆盖的风险：通用规则现在固定排在分档规则之前，并有级联顺序回归测试守护。
- 全量质量门禁提速：`npm run check` 改为单进程编排，测试按 suite 自动分片到最多 6 个进程并行执行（本机 2169 tests / 362 files 约 15 秒完成）。
- 开发流程约定调整：日常改动只需运行受影响的最小聚焦测试（`npm test -- <片段>`），全量门禁仅在提交代码与发版前各执行一次。
- 语法门禁口径收敛：进程内解析仅作快速路径，任何判定失败必须以 `node --check` 复核，兼容顶层 `return` 与 ESM 重试语义，避免误报。
- 补充语法门禁、runner 分片、皮肤级联顺序的回归测试与设计文档。
