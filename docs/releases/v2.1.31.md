# ChatUI v2.1.31

## Changes

- 输入区新增会话模型与思考强度一体化控件：无需打开菜单即可看到当前会话实际使用的模型和下一轮思考强度；“不思考”与五档强度统一可选，选择后立即关闭菜单并应用到后续请求。
- 思考内容改为独立着色面板：收到第一条思考或正文增量后立即停止等待计时并移除等待提示；思考完成后默认自动收起，可重新展开且内容不丢失；刷新时可恢复仅包含思考内容的进行中任务。
- 增强聊天任务完成恢复：空白回答、仅状态文本或节点被替换时不再被误判为已完成，会继续恢复并从持久化结果补齐；运行时升级不再直接删除可恢复任务，而是先校验服务端任务和执行契约。
- `UPSTREAM_TIMEOUT_MS` 改为首内容超时：只有完全没有收到第一段响应内容时才超时；收到首段内容后永久取消计时，后续静默时间不会中断已经开始输出的流。
- 修复公告空数据启动时先打开再关闭弹层造成的刷新闪现；公告请求失败继续 fail-closed。
- 图片指令物化兼容 JSON 模式供应商省略与状态对应的空伴随字段，同时继续严格拒绝语义字段缺失和协议异常。
- 修复选择“不思考”后思考强度菜单不自动关闭的问题。

- 思考展示、刷新续接、会话模型与思考强度控件已完成桌面和窄屏布局验证。
